## 1. 技术调研(先于实施)

| 来源 | 手法 | 对本批的作用 |
| --- | --- | --- |
| [Cyanilux Shoreline Shader Breakdown](https://www.cyanilux.com/tutorials/shoreline-shader-breakdown/) | 岸线泡沫 = **渐变/距离场 + 滚动噪声扰动 → smoothstep/距离衰减成带**;涌浪进退 = 沿渐变轴慢速余弦(swash) | 核心结构:**1D 位移的海岸线距离场**,而非噪声等值线 |
| [Fire Face Water(GLSL)](https://fire-face.com/water/) | edge foam:距离衰减 + 噪声图案调制,随波起伏自然弯曲 | 距离衰减 + 图案孔洞思路 |
| [Shadertoy GLOW TUTORIAL](https://www.shadertoy.com/view/3s3GDn) | 距离辉光 falloff | 核心/裙摆双段衰减 |
| [Crest Ocean(foam 参数)](https://crest.readthedocs.io/en/4.12/user/ocean-simulation.html) 等 | 岸线泡沫带宽度由距离场控制 | 带宽/密度参数化 |

碎花纹;参考图的海岸线束应建模为「**基线束 + 沿线 1D 蜿蜒位移 + 距离衰减**」。

## 3. 新实现:nightCoast 生物荧光海岸(luxShaders.ts,纯 GPU 层)

- **形态 = 海岸线束**:`coastDist` 内 4 条沿岸基线 `z = ∓0.115/∓0.345`(式
  `-0.345 + 0.23*k`),沿线 **1D 蜿蜒谱** 4 成分:λ 1.85/0.79/0.37/0.19m,
  幅 52/30/13/5mm(宽弧大弯为主、细弯点缀,总幅 0.10m ≤ 半间距,相邻线最坏
  反相不相交 → **结构按构造稳定**);距离按 `|Δz|/√(1+s²)` 做法向修正(线宽不随
  坡度变化)。→ 数条平行、横贯场景、长而不规则弯曲的连续亮线,严格还原参考图。
- **动态**:
  ①**整体横向移动**:采样坐标 `u = x − 0.045·t`(0.045 m/s 沿 +x 平移,模拟海浪,
  结构随平移保持);
  ②**局部形变**:蜿蜒相位慢漂移(0.09-0.21 rad/s → 缓慢弯曲)+ 局部线宽慢调制
  `width = 4.5mm×(1±0.35)`(λ 0.86m,周期 ~48s → 局部收缩/扩张)+ **涌浪** 整线
  沿岸向慢进退(幅 16mm,周期 ~39s);
  ③**非同步呼吸**:`0.72+0.28·sin(0.33t + 2.6·kb + 4x)` —— 周期 ~19s,相位随带序
  (kb)+ 沿线位置 → 各线各段缓慢、非同步。
- **亮度**:蓝白窄核心 `exp(−dn²·0.7)`(dn 单位=局部半宽,σ≈3-6mm)+ 蓝色辉光
  裙摆 `exp(−dn·0.18)×0.5`(~4-5cm,参考图裙摆较宽);核心色向白 mix 0.72;
  环境光由 NIGHT 预设压至近黑,亮度全部集中于边界局部(禁止均匀蓝光)。
- **颗粒**(uDotCell=0.021m 格点哈希):密度 `0.12+0.88·exp(−dn·0.22)` —— 边界附近
  最密、外围基量 12%(散布较宽,参考图颗粒场);极低速随机漂浮(双频慢摆 ±0.22
  格,各颗粒相位随机,**无统一方向**);随机生命周期(周期 6-20s,25% 淡入/28% 淡出)
  + 亮度缓变;尺寸高幂偏置 `pow(hash,7)` —— 多数 ~1mm、少量 ~4mm,亮度系数
  `(0.7+1.5·big)` → 仅少量越过 bloom 阈值泛辉光。
- **接入路径**:`shadeBottom`(水面/液滴折射视图)与水底 mesh 共用 `nightCoast`
  (与第八批同路径,不含 TS 镜像,无两侧同步约束;冒烟测试跟随)。

## 7. 教训

1. **「还原图片」先做形态结构选型**:各向同性噪声等值线 ≠ 海岸线;参考图是
   「平行线束」时必须显式建模线束(基线+沿线位移),噪声只能做细节调制。
2. **先调研业界成熟做法再动手**(委托方指示):shoreline foam 的「距离场+噪声
   扰动」范式直接命中本需求,避免了第八批的结构性返工。
3. 形态类改动必须**浏览器双帧截图验证动态**(静态单帧无法证伪「移动/形变/呼吸」)。
4. **`patch` 是 GLSL ES 保留字**(二次整改轮踩坑):用作变量名 → 四个共用
   COMMON_HELPERS 的材质片段着色器全部编译失败 → **场景全黑**(水面/水底/液滴/
   雾层一损俱损)。已改名 `clump`。诊断手法:`__gray.renderer.info.programs` 里
   失败程序的 `diagnostics.fragmentShader.log` 给出具体行号与原因。

### 8.3 改动明细

- **法向推进**:`coastDist` 基线改为 `fract(0.1+0.2k+0.016t+0.04·sin(0.16t+2.7k))·1.3−0.65`
  ——相位匀速前进(周期 ~62s,推进 ~0.021 m/s,每 ~12.5s 一波到岸,线束数恒定
  → 结构稳定)+ 涌浪 ±0.052m(周期 ~39s,推进中带停顿回退);**移除原 +x 横移**;
  波列 4→**5 条**(间距 0.26m)。蜿蜒谱/线宽调制/法向修正不变(随推进保持)。
- **颗粒加密提亮**:`nightDotCell` 0.021→**0.014**;密度 `(0.16+0.84·exp(−dn·0.16))×clump`
  (衰减放慢 → 扩散更宽;基量 16%)+ **低频热点** `clump=0.45+0.55·vnoise(2.9x,2.1z)`
  (成片闪砾)+ **近线提亮** `boost=1+0.7·exp(−dn·0.5)` + 亮度系数 0.7→0.85;
  生命周期在台率提高(淡入 18%/淡出 22%)。
- **宽域弱蓝晕**:`wash=exp(−dn·0.055)×0.1`(λ≈8cm)——线间水体深蓝感,随线距
  衰减保持局部性(非均匀蓝光)。
- **呼吸加深**:0.72±0.28 → **0.55±0.45**(局部可近乎熄灭,参考图线明暗起伏大);
  核心随呼吸 (0.45+0.55·breathe)。
- 测试 `luxNight.test.ts` 断言随新常量/新结构更新(法向推进 fract 式、5 波列、
  clump、wash、boost、呼吸幅度)。

### 8.4 三次反馈:颗粒贴线密集成带(同日晚)

> 委托方复验:光粒子依旧过少,不通过。要求:**光点紧贴亮线、密集近白,向外
> 缓慢稀疏变暗**;且光点应**随边界线一同运动**(非固定于世界网格)。

- **根因(「依旧过少」的真因)**:颗粒半径原按格点比例定义(`mix(0.05,0.16,big)`
  × 格点),格点一路缩小时半径随之缩到 **<1px,大量颗粒根本画不出来**;且上轮
  衰减取 0.55 过陡, concentration 对比有余而「缓慢渐弱」不足。
- **随动坐标系**:`coastDist` 增输出最近波列的**有符号法向偏移 ζ**;颗粒格点改取
  `(x, ζ)/uDotCell` —— 线的法向推进/涌浪/蜿蜒全部被颗粒继承,**光点贴线同行**;
  热点场同取随动坐标(热点随线迁移)。kb 切换处图案有跳变,但远场基量低,不显。
- **密度/亮度/白度三重梯度**(线处峰值,向外缓慢衰减):
  密度 `(0.10+0.90·exp(−dn·0.30))×clump`;亮度 `(0.45+0.55·exp(−dn·0.25))×1.5`;
  白度 `whiteMix=clamp(0.3+0.6·exp(−dn·0.4),0,0.95)`(线处近白、远处蓝)。
- **半径与格点解耦**:半径改绝对米数 `mix(1.5,4.5mm,big)`(恒 ≥1px);
  `nightDotCell` 0.011→**0.006**(6mm 粒间距 → 贴线颗粒带)。
- 验证:tsc 干净;vitest **172/172**;build 四入口通过。实机目验(120fps):
  每条亮线周围形成密集近白颗粒带、向外缓慢稀疏变暗,随线推进同行 ✓。
  ⚠ 排障备注:浏览器面板被遮挡时 rAF 节流至 ~10fps,Playwright 点击 actionability
  会超时,改用 `cua.click` 坐标路径 + HUD 固定按钮位即可。
