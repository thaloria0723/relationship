## 1. 三模块与依赖(互相独立的铁律)

```
交互系统 ──inject(intent)/查询──▶ 物理模型 ◀──快照/场采样── 光影渲染
   (three-free)                    (three-free)         (唯一 import three)
```

| 模块 | 职责 | 独立性验收 |
|---|---|---|
| ① 物理模型 | 水的状态:布点、漂浮运动、高度场、波场。**决定水在哪、怎么动** | import 图无 three/DOM;node 单测全绿 |
| ② 交互系统 | 输入→意图:命中/悬停/拖拽/聚焦/模式。**决定用户想做什么** | 无颜色/GLSL;mock 物理可测 |
| ③ 光影渲染 | 全部光学与像素。**决定水长什么样** | 不挂 DOM 事件;固定快照→确定性截图 |

接缝:**交互决定意图与目标,物理决定运动,渲染决定外观。**
`import three` 只允许出现在模块③——这是最强独立性证明,也是 three.js 社区惯例(库在边缘)。

## 3. 关键架构决策

1. **渲染库:three.js**(替代 PixiJS,修订总规格 §2 技术栈一行)。WebGLRenderer + GLSL3 ShaderMaterial;WebGPU/TSL 为后路不是现在(社区共识:主线在演进,WebGL 仍一等公民)。
2. **物理 CPU 单真源 + GLSL 镜像 + 契约测试**:场是解析式,GPGPU 不上(GPUComputationRenderer 留扩展位);交互需要 CPU 读写物理态。TS 参考实现(node 可测)与 GLSL 采样实现对拍。
3. **快照即接口**:物理产出滴心/半径/相位/squash 的扁平数据(three 原生支持 uniform 数组→Pixi v8 的 D0..Dn 烘焙坑消失);`toFixed(4)` 规则仅对字符串注入的常量保留。
4. **时间归物理所有**:物理持有 `simTime`(宿主喂数,交互无障碍策略可冻结);渲染只读。单一时间源。
5. **ShaderChunk 组合**:FRAG 拆命名 chunk(caustic/field/drop-optics/p2/p4/composite),材质由 chunk 拼装——three 内置材质自身的组织方式。
6. **EffectComposer 不急**:当前是解析式全屏 shader,多 pass 破坏像素等价;按需一个特效一个 Pass 地加。

## 4. 迁移陷阱清单(像素等价验收重点)

| 陷阱 | 对策 |
|---|---|
| 色彩空间(头号) | ShaderMaterial 不自动加 colorspace 转换,理论上与 Pixi 直出等值——**实测验证,不推理** |
| shader 前导 | three 接管 #version/precision;GLSL3 需显式 `out` 替代 gl_FragColor |
| GLSL 反向 smoothstep | 封版代码存在 `smoothstep(1.08,1.0,…)` 反向边(GLSL de-facto 可用);GLSL 镜像 chunk 原样保留,TS 兼容层按 de-facto 语义实现 |
| 时基 | three Clock;无头验证虚拟时间钉相位 |
| 运行时 | setAnimationLoop、setPixelRatio(min(dpr,2))、resize 观察、webglcontextlost/restored |

**像素等价验收**:同 seed+虚拟时间,three 版截图对 Pixi 基线(360a8f9 产物)逐像素差分,差值落噪声底(|Δ|≈1.4,锚点对齐)内 = 迁移无损。

## 6. 各模块规则(继承已踩坑)

- ① 物理:值与导数同步(契约测试数值验证)、PRNG 确定性(独立实现对拍)、改布点参数必重验 seed(40 次退化强放是静默失败)。
- ② 交互:转场期冻结输入、章节滑块 150ms 防抖+松手触发;命中=解析圆测试(不用 Raycaster)。
- ③ 渲染:toFixed(4)、pow 底数≥0、无数组 uniform 限制已消除、钳制防平顶、分支从 dr≥1.0 连续起坡、无头截图+Python 解 PNG 验证。

## 7. 开发顺序与验收物(模块顺序:物理→交互→光影)

1. **模块① 物理提取**:contracts + physics TS 模块,契约测试全绿;index-wave.html 零变化。← 当前阶段
2. **模块② 交互建立**:状态机+命中(three-free)单测绿;可见反馈待模块③底盘。
3. **模块③ 渲染**:three 无损迁移(verbatim FRAG+uniform 数组+emphasis 钩子)→ 像素等价验收 → 悬停/拖拽/聚焦可见验收 → chunk 重组(纯重构,再次差分)。

每步交用户验收后才进下一步。
