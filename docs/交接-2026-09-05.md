## 勿重蹈的坑

1. GLSL `pow(负数,x)`=NaN；JS `3.0`→"3" 注入编译错误——**所有注入数字 toFixed(4)**；rippleRings 暗前缘已改乘法形式防负底数
2. PixiJS v8.20 uniform **不支持数组**→ 液滴布点烘焙常量 D0..Dn + dropAt 选择器
3. Pixi 首渲染才编译 shader 且**吞错误**→ 无头截图 + 纯 Python 解 PNG；改前/改后同 seed 截图**逐像素差分**最有效，但两帧 bob/sway 相位不同需**锚点对齐**；远背景 |Δ|≈1.4 是噪声底
4. headless rAF 只泵 ~1 帧 → 验证渲染用行内亮度 sd（≈0 = CSS 兜底渐变）
5. **分支结构会产生高斯公式没有的硬边**（影子分支曾从 dr>1.08 才开始）；**钳制削出平顶=贴纸感**（钳制要放在散度峰值之外只防极值）——这两条是本轮「太假/硬边」的真正根源
6. 布点避让：dropCount/尺寸范围一改就要重新验证 seed（有 40 次退化强放的静默失败模式），验证脚本思路见 git 历史与上会话：模拟 Lehmer 序列检查间距比/屏边/投影余量
