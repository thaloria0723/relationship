## 0. 需求原文(判定基准,勿改写)

**大转折动画**(动效总纲 §5;产品规格 §8.3,≈2.5-3.5 秒,三阶段):

1. **汇聚(旧章结束)**:所有水滴失去浮力,受重力或向心力影响,像水珠在荷叶上
   滚动一样,迅速向屏幕中心或某个「黑洞/漩涡」汇聚,线条随之卷曲、缠绕,最后融为一体。
2. **过渡**:画面可能是一滴巨大的水珠悬停,或者是一瞬间的模糊(类似水下视角的焦散效果)。
3. **迸发(新章开始)**:大水滴炸裂/飞溅(Splash),无数小水珠向四周飞射,在空中减速、
   悬停(效果类似于时空静止),然后被无形的线牵引,慢慢拉长、连接,最终定格为
   新章节的关系网。

**交互规则**(视觉规格 §6 ② + 产品规格 §8.4):

- 转场期**冻结输入**(1-3 秒禁用拖拽/点击),结束恢复;
- 章节滑块 **150ms 防抖 + 松手触发**(快速拖动不逐章连播);
- 跳跃式切换 = 全区间 delta **一次**转场(不逐章连播);
- 初次加载直接渲染当前章节状态,**不触发**转场。

**张力阈值**(产品规格 §8.1):张力 = Σ 权重(新人登场 importance×0.5 / 死亡
importance×1.5 / 新关系 strength×平均importance×0.6 / 关系结束 ×0.8 / 类型变化 ×1.0,
敌友反转按 1.5 取上限),阈值 T=1.0,≥T 走大转折;<T 走小变化(本轮不实施演出,
只落实公式与分支)。权重集中在一个常量文件,设计为可按书覆盖。

**文字上滴**(动效 §1.1「水滴表面需清晰显示对应人物的名字」+ 委托方 2026-09-12):
文字标**在液滴上**(不再挂滴下方),无背景底牌、无边框,重新解决可读性。
两条既有验收标准继续有效:①文字与画面风格一致、能融入;②文字清晰可见。

### 1.2 互联网参考(步骤 3 检索结果)

- **motionsites.ai**(委托方推荐):高端动效网站提示词库(Lovable/Bolt/Cursor 用),
  含 Liquid Glass 组件、3D scroll 动效、Framer Motion 编排课。本轮取其**质量口径**
  而非代码:电影级缓动(冲击前蓄力、冲击后过冲回稳)、编排节奏
  (anticipation → impact → settle)、克制的高光与辉光。大转折的
  「汇聚蓄力 → 爆发冲击 → 悬停定格 → 牵引归位」按此节奏设计。
- **three.js 粒子 morph 成熟做法**([Kshitij978/Three.js-Point-cloud-morphing-effect](https://github.com/Kshitij978/Three.js-Point-cloud-morphing-effect)、
  [mmdalipour/particle-morph](https://github.com/mmdalipour/particle-morph)、
  three.js Discourse「particle morph with custom shader」讨论):两组目标位置之间
  粒子插值,中间态叠加**漩涡/噪声位移**;本质 = `pos = lerp(A, B, ease(t)) + swirl(t)`。
  本轮迸发段采用同一数学形态(中心 → 过冲半径 → 槽位,中段叠加旋绕)。
- **实现路线取舍**:GPUComputationRenderer(GPGPU)是社区常见路线,但本工程纪律是
  「物理 CPU 单真源 + 效果纯逻辑可单测」(fxdriver 先例),且验证页粒子量级
  (≤48)远不到 GPGPU 必要量 → **CPU 驱动 + 逐实例矩阵**,与雾团/液滴通道同构。

### 1.3 本代码库已验证、直接复用的通道(步骤 2:现有代码盘点)

| 通道 | 出处 | 在大转折中的用途 |
| --- | --- | --- |
| `dissolve`(hashed discard,1=全丢→0=完整) | 死亡/灰滴「从无到有」 | 新章液滴**物质化**就位(不写深度不留洞) |
| `bridgeGrow`(半径生长/回缩,几何非 alpha) | 凝结抽桥/死亡回缩 | 旧桥卷入收缩;新桥牵引起线 |
| `flash`(HDR 闪点,shader 内钳制) | 凝结闪点 | 爆散瞬间的闪光峰值 |
| 雾团 billboard 池(`fogMesh`,容量 8) | 凝结起雾/死亡残雾 | 过渡段巨滴周围的水汽包裹 |
| `aFx.absent` 灰度 + `scale`/`lift` | 聚焦灰滴 | 汇聚段旧滴缩尺/沉浮 |
| `uDim`(聚焦压暗,`luxSys.update` 已有) | 聚焦模式 | 过渡段「水下视角」整体压暗 |
| `FxSource` 注入(null = 与生产逐字节等价) | B 组全部效果 | 大转折同样以注入源接入,不碰生产路径 |

关键约束(交接 §3 铁律):uniforms 被五个材质共享 → 逐桥状态只能走**逐顶点属性**;
`three` 只许 viewer.ts import;液滴不透明写深度 → **一切出场/退场禁用 alpha 淡入**
(只走 dissolve/scale/lift)。

## 2. 总体设计

### 2.1 时间线(mode 9「大转折」,总长 3.3s,落在规格 2.5-3.5s 区间)

```
0            1.05        1.75   2.05              2.85     3.05   3.30
├── ① 汇聚 ──┤├─ ② 过渡 ─┤├burst┤├─── ③ 迸发 ────┤├─定格─┤
   旧滴螺旋滑入中心      巨滴悬停   爆散:闪 + 火花   火花被牵   新滴物质化
   旧桥卷入收缩+卷曲     +雾+压暗   飞射→减速→悬停   引到槽位   新桥抽出生长
```

- **汇聚**(0→1.05s):旧章 7 滴(中心 + 六边形)沿**螺旋路径**滑向中心
  (`pos = lerp(原位, 中心, easeInCubic) + 旋绕切向偏移`),尺度 1→0(被巨滴吞并);
  旧桥 `grow` 1→0(卷入收缩),叠加**卷曲位移**(中段横向正弦缠绕,幅度 ∝ 剩余量)。
  「像水珠在荷叶上滚动」= 贴水面滑行(不加 lift),旋绕提供「卷曲、缠绕」读感。
- **过渡**(1.05→1.75s):中心滴长成**巨滴**(scale 1→4.2,微幅呼吸),
  雾团包裹(复用 fog 池),`uDim` 压暗 + bloom 增辉 → 「巨滴水珠悬停 + 一瞬间
  水下焦散式模糊」的观感由「压暗 + 辉光 + 雾」三件套承担(不引新 post pass,
  保住像素等价纪律)。
- **迸发**(1.75→3.05s):burst 瞬间(1.75→2.05)巨滴 flash 峰值 + scale→0;
  **火花池**(新,容量 48 的透镜小滴 InstancedMesh)从中心向四周飞射:
  径向 `easeOutCubic` 减速 → **悬停段**(≈0.3s,微颤,时空静止感)→
  被牵引(改善 easeInOut)飞向新章槽位。新章 6 滴在槽位**物质化**
  (dissolve 1→0,错峰),旧核心退场。
- **定格**(3.05→3.30s):新桥 `grow` 0→1(抽丝生长,复用凝结通道),
  波纹平息,网络稳定。

### 2.2 场景与数据

- **旧章** = 网络场景(中心 + 六边形环,同 HUD「网络」按钮布局,确定性);
  **新章** = 中心 + 五环滴(旧章一名成员退场不回归)+ 一环滴外移(关系变淡)——
  布局差异肉眼可辨,证明「定格为新**章节**的关系网」。
- 角色表按模式解释:mode 9 用 `ROLE_T_OLD=0 / ROLE_T_CORE=1 / ROLE_T_NEW=2+序号`
  (与 mode 8 的 ROLE_ABSENT 编码互不越界)。
- 引擎真值不变:**编排全走渲染侧偏移**(`FxDropletParams` 新增 `ox/oy` 世界偏移,
  syncDroplets 液滴矩阵、syncBridges 桥端点同步应用 → 滴与桥永不脱节);
  汇聚末真删旧滴、爆散时 `spawnDroplet` 新滴(入队下一固定步生效,既有时序),
  新滴物理在槽位自然落定,转场结束后渲染偏移归零、物理接管。
- **火花池** = 新 `sparkMesh`(复用透镜几何 + 新廉价珠光 ShaderMaterial,容量 48,
  renderOrder 6),`FxSource.sparkAt(i)` 未注入时 count=0,生产零开销。

### 2.3 交互规则落实(视觉规格 §6 ②缺失项)

- **张力/滑块纯逻辑** `fxspike/tension.ts`(three-free、可单测):
  §8.1 权重常量表 `TENSION_WEIGHTS`(可按书覆盖的 override 参数)+ 阈值 T=1.0;
  `deltaEvents(events, from, to)`(区间 (from,to] 叠加,跳跃 = 全区间一次);
  `tensionOf(delta)`;`branchOf(tension)` → `'minor' | 'major'`;
  `SliderGate` 类:150ms 防抖 + **松手才触发** + 跳跃不逐章(状态纯逻辑,DOM 无关)。
- **转场期冻结输入**:触发转场时 `controller.freezeLeft = 转场总长`
  (控制器已有冻结通路,聚焦转场在用);验证页经 `__gray.controller` 设置。
- **首载不触发转场**:滑块仅在「目标章 ≠ 当前章」时触发;初值即当前章。

### 2.4 文字上滴重做(labels v3)

- 锚点改**滴心**(不再 1.35r+8px 下移);字号随投影半径自适应

- 无底牌无边框不变(v2 已无);可读性新解:**字色按「落在什么上面」选**

## 5. 风险与边界

- **物理与编排解耦**:汇聚段滴在引擎里没动(偏移是渲染侧)→ 波场不会跟着「滚」;
  涟漪感由桥卷曲+滴缩尺+雾承担。真涟漪(爆散拍水)由 spawn 落滴自然产生,不另造假波。
- **交换删除索引位移**:旧滴从高索引往低删;新滴生成后角色表同步重建
  (transitionSettle 幂等,重播/取帧两条路径都走同一函数)。
- **重播正确性**:进入/重播 mode 9 一律强制重建场景(避免从转场中段重播)。
- 转场时长 3.3s ≈ 冻结上限 3s(§8.4「1-3 秒」取上沿,含定格收尾 0.25s 松绑)。
- 小变化动画(§8.2 五阶段)本轮**不做演出**,只落实公式与分支(委托方开题范围 =
  大转折;小变化另开)。
