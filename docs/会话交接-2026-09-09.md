## 5. 关键裁决与教训(新会话 勿翻案/勿重蹈)

1. **ShaderMaterial 内建属性缺失静默降级**:自建几何若不提供 `uv/normal`,three 绑定默认值
   `(0,0)` 不报错——第六批「涟漪只在水底可见」的根因即水面网格缺 uv。新增网格必须显式建齐。
2. **液桥锚点与液滴渲染同源**(`lensBottomY`/`lensMidY`,viewer.ts):贴水/悬浮/退场曲线
   三态统一从一处取锚,改液滴形态只动这一处;桥尖端 0.866r 解析交点使「无插入段+不脱节」
   按构造成立(透明液滴不能靠深度遮挡)。
3. **水底取色必须按屏显校准**:albedo × 光照在 ACES 前可达 2-3,>1 的通道一律压白;
   正午按屏显校准取了深系数 [0.10,0.22,0.42],"浅蓝"是色调映射后的结果。
4. **环境波涛是视觉层**:只进渲染(顶点位移/法线/焦散),不进物理场;液滴贴浪走 TS 镜像,
   坡度力/耦合仍只吃仿真场(免反馈回路不被扰动)。
5. **透明液滴语义**:液桥从液滴后方经过会透见(接受);液滴间互相透视亦然
   (renderOrder:水底不透明最先,水面 0,液滴 5,液桥 10)。
6. **沿用的既有裁决**:桥=关系网的边(连接语义,距离无关成桥)、拉伸不断裂、液滴尺寸恒定、
   聚焦编舞守护(guardSlot/formationFrozen)、桥常态透明度 30%、夜光点色彩
   (**金色裁决已被第八批推翻 → 生物荧光蓝 b>g>r**,见 §8 与 docs/观感与交互调优-2026-09-09-第八批.md)。
7. **液滴光学三层合成是本轮裁决,勿回退**:`index-wave.html` 液滴的分离度/厚度感来自
   「折射+反射+Fresnel」;**禁止改回**整体压暗(`*0.94`)、对比拉伸(`1.28+0.42`)、白色点高光
   (win 0.26 / sp 0.45)——方案 §4/§6/§7 明令、验收确认。水色修正只允许 `vec3(0.98,1.0,1.02)`
   量级。所有 `pow` 底数必须 ≥0(clamp/max 先行,本轮新增的 skyUp/sunHit/cosTheta 均已保证)。
8. **两套液滴实现互不同步**:`index-wave.html`(PixiJS 原型,Fresnel 三层)与 web/ 工程的
   luxview 液滴(three.js,正半球 Snell+Fresnel+淡蓝染色)是独立文件、独立参数、独立风格声明,
   勿把一方的参数/结论直接搬到另一方。

9. **域扭曲折叠约束**:扭曲场 ‖∇W‖ 峰值必须 <1(否则坐标映射折叠翻转,波场出现鬼影);
   `luxWaves.test.ts` 以 Σ b·k<1 守护。链式法则导数在 W=0 时须退化为原公式——
   改谱/改扭曲后须跑该测试确认退化与界。
10. **执行环境进程数饱和降级**:ulimit -u=500 打满后 Bash 无法 fork 任何外部进程
    (tsc/vitest/build/git 均 Sandbox Error)。此时 Read 仍可用(不 fork)。降级流程:
    Read 逐文件复核代码(类型/GLSL 语法/数学)→ 交付 → 交接文档如实注明 → 下次会话首跑确认。
    勿反复重试同一命令(进程不会释放)。
