## 5. 关键裁决与教训(新会话 勿翻案/勿重蹈)

1. **ShaderMaterial 内建属性缺失静默降级**:自建几何若不提供 `uv/normal`,three 绑定默认值
   `(0,0)` 不报错——第六批「涟漪只在水底可见」的根因即水面网格缺 uv。新增网格必须显式建齐。
2. **液桥锚点与液滴渲染同源**(`lensBottomY`/`lensMidY`,viewer.ts):贴水/悬浮/退场曲线
   三态统一从一处取锚,改液滴形态只动这一处;桥尖端 0.866r 解析交点使「无插入段+不脱节」
   按构造成立(透明液滴不能靠深度遮挡)。
3. **水底取色必须按屏显校准**:albedo × 光照在 ACES 前可达 2-3,>1 的通道一律压白;
   正午按屏显校准取了深系数 [0.10,0.22,0.42],"浅蓝"是色调映射后的结果。
4. **环境波涛是视觉层**:只进渲染(顶点位移/法线/焦散),不进物理场;液滴贴浪走 TS 镜像,
   坡度力/耦合仍只吃仿真场(免反馈回路不被扰动)。
5. **透明液滴语义**:液桥从液滴后方经过会透见(接受);液滴间互相透视亦然
   (renderOrder:水底不透明最先,水面 0,液滴 5,液桥 10)。
6. **沿用的既有裁决**:桥=关系网的边(连接语义,距离无关成桥)、拉伸不断裂、液滴尺寸恒定、
   聚焦编舞守护(guardSlot/formationFrozen)、桥常态透明度 30%、夜光点金色(r>g>b 测试锁定)。

## 7. 运行 / 验证 / 调参

```bash
cd web && npm install        # 首次
npm run dev                  # http://localhost:5173|5174/luxview.html
npm test                     # 137 例(含 10k 步稳定性回归,~30s)

```

- 物理参数唯一真源:`web/src/watersim/params.ts`(默认值 + RANGES,越界启动即 throw)。
- 光照/渲染参数唯一真源:`web/src/lighting/presets.ts`(LightingPreset 四时段 + RENDER_PARAMS)。

  两侧不可单独改数)。手感微调入口:`RENDER_PARAMS.ambientWaveAmp`(全局幅度)。
- dev 探针:控制台 `__gray.engine / .controller / .meshes / .screenOf(i)` 可观测引擎态。
