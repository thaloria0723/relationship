
# 四、必须真正加入 Fresnel

液滴 shader 中必须实际计算并使用 Fresnel。

加入类似：

``` glsl
vec3 V = normalize(vec3(0.0, 0.0, 1.0));

float cosTheta = clamp(dot(N, V), 0.0, 1.0);

float F0 = 0.0204;

float fresnel =
    F0 +
    (1.0 - F0) *
    pow(1.0 - cosTheta, 5.0);
```

要求：

-   液滴中心 Fresnel 较低
-   液滴边缘 Fresnel 增强
-   不形成明显白色描边

**Fresnel 必须真正参与最终颜色。**

# 五、必须真正加入环境反射

不能只计算 Fresnel。

``` glsl
vec3 reflectedColor;
```

或者等价的 `reflectionColor()` 函数。

反射颜色不能直接使用纯白。

可以使用简化环境模型：

-   上方晨光
-   浅蓝天空
-   水面环境
-   当前背景亮度

例如：

``` glsl
vec3 reflectionColor(...)
{
    // 根据 N、V 和当前环境构建柔和反射
}
```

不要求建立完整 HDR 环境贴图。

目标是：

> 液滴边缘出现柔和的环境反射，而不是白色塑料边缘。

# 十三、液滴 shader 的目标结构

实际实现可以根据现有代码调整，但核心逻辑必须保持：

``` glsl
// 1. 液滴法线
vec3 N = ...;

// 2. 观察方向
vec3 V = normalize(vec3(0.0, 0.0, 1.0));

// 3. Fresnel
float cosTheta = clamp(dot(N, V), 0.0, 1.0);

float F0 = 0.0204;

float fresnel =
    F0 +
    (1.0 - F0) *
    pow(1.0 - cosTheta, 5.0);

// 4. Snell 折射
vec3 R = refract(...);

// 5. 折射后的水面
vec3 refractedColor =
    sceneColor(refr);

// 6. 环境反射
vec3 reflectedColor =
    reflectionColor(...);

// 7. Fresnel 合成
vec3 dcol =
    mix(
        refractedColor,
        reflectedColor,
        fresnel
    );

// 8. 非常轻微的水色修正
dcol *= vec3(0.99, 1.0, 1.01);
```

核心关系必须是：

``` text
折射
+
反射
+
Fresnel
=
液滴主体
```
