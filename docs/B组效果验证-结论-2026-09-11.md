## 2. 逐效果判定（判据一：对照动效文档文字）

| # | 效果 | 文档要求 | 实测 | 判定 |
| --- | --- | --- | --- | --- |
| 1 | 融合 | 液桥**粗壮近似无边界**；高光或微气泡**双向缓慢流动** | 双向相位流动 ✓；微气泡单元量化 ✓（8 格 = 规格硬上限） | **部分达成** |
| 2 | 极限拉扯 | 中间**极细、濒临断裂**；线上**光泽黯淡** | 颈径屏幕空间下限 + Rayleigh–Plateau 珠化 + 撤锐高光 + 去饱和 + 降透明 | **达成** |
| 3 | 湍流 | 液桥**变得极粗**，边缘**不规则水花飞溅或沸腾状**；两水滴**自身高频颤动** | 轮廓噪声侵蚀 + 水沫带 ✓ | **部分达成** |
| 4 | 暗流 | 密集微小气泡/光点**单向快速冲刷、无回流** | 单向相位 + 16 格密排气泡 | **静态达成**（动态待验） |
| 5 | 潜流 | 平时半透明融入背景；鼠标靠近才像**搅动泥沙般慢慢浮现流动纹理** | 指针距离 → reveal dissolve（底→上方向性 + 快进慢出 + 沉积色前沿） | **达成** |
| 6 | 凝结登场 | **起雾 → 聚拢 → 凝结成滴 → 抽丝拉出液桥** | 雾团淡入收缩 + 液滴缩放过冲 + **几何抽出**的桥 | **达成** |
| 7 | 死亡蒸发 | 边缘**沸腾模糊 → 化作水蒸气上飘 → 液桥断裂 → 原位残留雾气** | 顶点沸腾 + 热晕 → 缩小上飘 → **抖动溶解** → 残雾 | **基本达成** |

**汇总**：达成 3、基本达成 1、部分达成 2、静态达成 1。

### 各效果的具体缺口

**1 融合 —— 差「粗壮近似无边界」**
粗细没有随关系强度变化。这依赖清单 A-2 的「关系强度 → 粗细与弹簧强度」映射，本轮未接。
「近似无边界」需要水滴靠近到极限并让融合倒角接管，同样依赖位置编排。

**3 湍流 —— 差三项**
①「极粗」没做（只做了边缘）；② 水花飞溅粒子没做——工程侧有硬约束：弹坑池仅
`maxDroplets = 7` 槽且满池退化为单步注入（`engine.ts:135-150`），飞溅必须限流
（每桥 ≥0.2–0.3s 合并成一次）才能上线；③ 两滴「自身高频颤动」没做。

**4 暗流 —— 动态特性单帧证不了**
「单向」「快速」「无回流」都是时间维度属性，静态截图只能证明内部结构存在。
**需要录屏才能判定**。

**6 凝结 —— 雾偏淡；「聚拢」是半径收缩而非位移聚拢**
雾团本就与滴同心，所以「聚拢」表现为半径收缩，没有真正的位置汇聚。

**7 死亡 —— 残雾对比度低；「水蒸气上飘」目前是液滴整体上浮的近似**
没有真正的蒸汽粒子系统。溶解（抖动丢弃）一项观感最好，读作「化作细小水滴/雾散去」。

## 3. 逐技法判定（判据二：对照调研的原技术/参考）

| 技法 | 参考来源 | 实测是否符合参考特征 |
| --- | --- | --- |
| **hashed alpha discard** | three 官方 `alphahash_pars_fragment`；Wyman 2017 *Hashed Alpha Testing* | **符合**。点状溶解、无「球看不见但深度还在挡桥」的洞——正是参考资料描述的判据 |
| **亚像素诊断 → 屏幕空间颈径下限** | 本项目自行推导（无外部参考） | **有效**。这是「黑刀片」的真正解药；且修掉了上一版「锥形被抬平、桥变粗圆棒」的连带错误 |
| **Rayleigh–Plateau 珠化** | Wikipedia *Plateau–Rayleigh instability* | 已实现，是否可读需人眼判定；与「拉伸不断裂」裁决兼容 |
| **单元量化气泡（减性暗体）** | IQ *Bubbles*（ShaderToy 4dl3zn，**声明禁止移植，只读原理**） | **部分不符**。减性暗体用了，但**没有「贴边回升」的环状结构**（参考里 `color -= col.zyx * (1-smoothstep(...))` 的关键在于环），故目前读作「暗斑」而非「气泡」 |
| **Dissolve 前沿色带** | Ronja #038；Alisavakis | 潜流已用沉积物色前沿（参数倒序的反向 smoothstep） |
| **体积水汽 billboard** | TrentSterling/threejs-volumetric-beam | 单 draw call 池化 + 与 `LUX_MIST_FRAG` 同族噪声已实现；**对比度不足**（正午水面近白，白雾落上去等于没有对比，已改为偏灰体色） |
| **湍流：轮廓侵蚀 + 水沫带** | 调研综合 | 与参考一致；曾因 `rim` 方向写反把管子掏成空心（中心 rim=0），已修 |
| **去同步（每桥相位）** | 夜闪三次整改的教训 | 已实现（`aSeed` 静态属性，init 填一次） |

## 4. 工具与流程产出

- **取帧机制（可复用）**：本机 headless Chrome 可渲 WebGL；但 `--virtual-time-budget`
  **推不动 `simTime`**（实测 9 秒预算只到 0.06s），故验证页做成 **URL 参数驱动的同步预滚**
  （`?fx=N&t=T&shot=1` → 推进仿真到稳态 → 置效果时刻 → 暂停仿真 → 渲一帧停住）。
  暂停仿真这一步是**确定性关键**：`uTime` 取自 `simTime`，不暂停则噪声图案每帧变化、截图不可复现。
- **副本边界**：`web-fxspike/` 目前**未跟踪、不进 git**；生产 `web/` 零改动。

## 5. 总评与建议

**不返回步骤 3。** 技术路线不需要推翻——判据二里除「气泡环状结构」一项外，核心技法路径都与
参考实现一致，且上一版的根本失败（亚像素「黑刀片」）已被定位并修复。

**建议进入「补齐缺口」的一轮迭代**，按优先级：

1. **湍流补三项**（极粗 / 飞溅粒子限流 / 液滴颤动）——文档要求最明确、缺口最大。
2. **气泡补「贴边回升」的环状结构**——让气泡读作气泡而不是暗斑；这是唯一与参考实现明显不符的一项。
3. **凝结的雾加密度、死亡残雾加对比**——两者都受「亮水面上白雾无对比」制约，可能需要改用
   「比背景略亮 + 有结构」而非「比背景略灰」的表达。
4. **融合/拉扯接「关系强度 → 粗细」映射**——依赖清单 A-2，属另一条线的输入。
5. **录屏补动态判定**——暗流（单向/无回流）、融合（双向缓慢）、湍流（高频颤动）三项
   本质是时间属性，静态截图证不了。
