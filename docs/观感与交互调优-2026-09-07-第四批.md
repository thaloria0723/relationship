## 抖动根因分析与实测数据

复现方法:headless 复刻页面循环(`engine.advance(1/60)` + 投影快照 + `controller.update` + 意图派发),指针静止在进入容差圆内不同偏移处,统计 8s 内悬停进入/退出翻转次数(S=675 px/m,与默认相机量级一致)。

### 根因 A(主):悬停升力把液滴「抬离」指针 → 进入-退出极限环

- 第三批②的 ×1.6 固定退出滞后按「位移数像素」标定;实测升力全程抬升的**屏幕像素幅度随液滴大小与变焦缩放变化**:默认视距下 r=0.02 → 15.8px、r=0.028 → 21.6px;2× 变焦下达 31.6–43.2px。
- 指针停在圆缘下方(进入半径 ≤ cr+14px)时的循环:进入 → 抬升把圆心带离指针 → 超出固定滞后带(余量仅 0.6×(cr+14))→ 退出 → 回落 → 再进入 → …。实测 8s 翻转次数:r=0.028、zoom×2、进入偏移 +40/45/50px → **82/210/294 次**(液滴剧烈上下弹跳;退出期 hoverWater 涟漪在指针处反复轰击液面,加剧观感)。
- 第三批插桩「363 帧稳定不翻转」为居中指针 + 小升力场景,未覆盖「圆缘 × 大滴 × 变焦」组合,故修复后残留。

**修复(悬停自运动补偿)**:进入悬停时记录目标屏幕圆心(`hoverEntryX/Y`);退出带 = `1.6×(cr+14) + |当前圆心 − 进入圆心|`。液滴被自己的升力抬走多少,退出带就扩多少——「指针不动、液滴自己动」在构造上不再触发退出(三角不等式:dist(pointer, current) ≤ dist(pointer, entry) + 自运动 < 滞后圆 + 自运动);指针真正离开(超出滞后圆 + 自运动量)才正常退出,拖拽松手转悬停同样重记录基准。

复测:同矩阵全部 **0 次翻转**(进入圆缘 ±1px 的 knife-edge 偶发单次进入后持续保持,无循环);控制器单测锁定「上移 40px 不翻转、超出带 95px 正常退出」。

### 根因 B(次):悬停涟漪泵的高频颤动

- 特性②每 0.108s 向悬停液滴位置注入 ~1.3mm 凹陷源(σ=0.8r),浮态「逐帧硬贴水」(z = 总高 + (R−d))使液滴以 ~9Hz 颤动,稳态 z p-p 实测 **1.31mm**(默认视距 ~0.9px,变焦后放大)。
- **修复(贴水随动)**:新增参数 `zFollowTau=0.1s`——浮态贴水改一阶随动(`z ← z + (zTarget − z)·(1−e^(−dt/τ))`),只削高频;升力浮出(τ=0.3s)与慢波 riding 基本无衰减;`zFollowTau=0` 退回硬贴。稳态 z 波动实测 **1.31 → 0.25mm(p-p)**,测试锁定 ≤0.8mm。
- 备注:升力全程抬升含耦合隆起约 2.5s 收敛(慢瞬态),非颤动,测试窗口取收敛后 2s。
