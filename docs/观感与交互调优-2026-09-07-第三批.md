# 观感与交互调优 · 第三批(2026-09-07)

委托方验收反馈 2 项 + 会话中途裁决修订 1 项(连接语义)。本文档为实施记录(新档,不改既定计划文档)。

## 反馈与修订

| # | 反馈 | 修订 |
|---|---|---|
| 1 | 液桥过宽,液滴间距过窄;桥形要求**两端略宽、中间收窄** | 渲染:桥跨距改**表面到表面**(两端各内嵌 0.75r,接头藏入液滴);端径 1.0·min(r)→**0.55·r**(两端按各自液滴张开,大滴端更粗),颈径 0.62→**0.45·min(r)**(颈/端比 ≈0.82,短桥近圆柱调研区间)。物理:张力改**双侧弹簧**(原绳式仅拉伸出力,毛细把成桥对拉到贴合) |
| 1′ | **裁决修订(会话中途)**:液桥=关系网的边,**重点是连接而非毛细作用**——不管两滴相距多远都能相连;液滴间距过小须根治 | 成桥**距离无关**:去掉 bridgeRange 距离门槛,任意两漂浮滴(冷却完毕、未成桥、桥轴无第三方占据)持续 drainTime 即成桥。restLen = **max(成桥距, rSum·(1+bridgeRestGap))**:远距对保持当前距离(连接而非收缩),近距对被推开到**净间距 ≥ 1.0·rSum**(bridgeRestGap=1.0)。桥池扩容 maxDroplets → n(n−1)/2(完全图边数,viewer bridgeMax 同步) |
| 2 | 液滴到处乱飘、移动阻力过低、运动后未自动弹回初始落点 | 新增 **driftDamping=2.5 s⁻¹**(风格化线性阻尼叠加在 Stokes 上,后者对厘米级液滴仅 ~0.05 s⁻¹)+ **homeK=4 s⁻² 落点回位弹簧**(始终朝出生锚点,与 driftDamping 组成欠阻尼回弹);pinRadius 0.06→0.03。拖拽释放:快拖/慢拖小幅一律**弹回初始落点(出生锚点)**;重锚定门槛 OR→**AND**(拖住 ≥1s **且**位移 ≥0.15m 才把锚点迁到松手处,保留用户布置关系网能力) |

## 连带修正(实施中发现)

- **断桥 pending 清零**:原距离门槛隐式承担了「断桥后成桥计时清零」;距离无关化后在 `breakBridge` 显式清 pending,否则冷却结束瞬间凭旧计时重桥,断裂形同虚设。
- **removeAt 字段搬运补全**:交换删除原先漏搬 homeX/homeY/lift/drag/returning/lev(聚合/悬浮路径下状态错位)。
- 「网络」场景 ring 0.034→**0.12** 展开为大间距网络(连接语义下 6 辐条+6 环边+6 次邻接长桥共 18 桥,3 条穿心直径桥被胶囊排斥自然剪枝)。
- demo:初始对回 0.45/0.55;落滴 A 落点 (0.5,0.5)→(0.5,0.64) 避开中央对桥轴(否则触发侵入治理剪断该桥);字幕同步连接语义。
- 坡度漂移测试合同更新:从「2s 内漂 >2mm」改为「坡度响应仍存在 + 漂移有界(<pinRadius)+ 波停后回位(<4mm)」。

## 参数变更总表

| 参数 | 旧 | 新 | 说明 |
|---|---|---|---|
| bridgeRestGap | —(新) | 1.0 | 成桥持距下限净间距(×rSum);范围 [0.05, 2] |
| driftDamping | —(新) | 2.5 | 漂浮滴水平漂移阻尼(s⁻¹);范围 [0,10] |
| homeK | —(新) | 4 | 落点回位弹簧(s⁻²);范围 [0,30] |
| pinRadius | 0.06 | 0.03 | 自由漂移区减半 |
| bridgeBreakStretch | 1.2 | 0.7 | restLen 变长后保持绝对断裂距离 ~2.1×rSum |
| bridgeTensionK/C | 8/2 | 8/2(语义改双侧) | 绳式→双侧弹簧 |

# 第二轮(同日,委托方追加反馈 3 项)

## 反馈与修订

| # | 反馈 | 修订 |
|---|---|---|
| 1 | 液桥依旧过宽,再收窄(尤其两端) | 端径 0.55r→**0.36·r**(两端按各自液滴)、颈径 0.45→**0.30·min(r)**;新增**拉伸变细**:管径 ×√(restLen/dist)(体积守恒观感,拉伸成细丝) |
| 2 | 悬停液滴快速异常抖动 | 根因:悬停升力抬升液滴 → 屏幕圆上移数像素 → 指针在圆缘时命中态**帧率级翻转** → 升力目标 0/1 抖动 + 交替注入 hoverWater 涟漪。修复:控制器**悬停退出滞后**(退出容差 = 进入容差 ×1.6;插桩实测升力全程抬升 31px 期间悬停稳定保持) |
| 3 | 移动阻力分情况:被控滴同现状;牵连滴阻力极大只被轻微拽动,桥拉伸不断裂 | ①桥张力**拖拽期单侧**:被拖端零阻力(手感同无桥),只牵拉未被拖端;②**牵连位移圈** `dragAnchorShift=5mm`:拖拽期间未被拖的漂浮滴离出生锚点超过 5mm 即位置投影回圈 + 削外向径向速度(位置级硬约束,不依赖弹簧刚度比);③**拉伸不断裂**:删 bridgeBreakStretch(断桥唯一途径=侵入治理);④重锚定释放时 `rebaseRestLengths`:桥 restLen 重定为当前距(距离变化被连接吸收,牵连端不被继续拖向旧距离) |
