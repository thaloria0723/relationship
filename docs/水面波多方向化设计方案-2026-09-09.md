# 水面波多方向化设计方案（2026-09-09）

> 任务来源：委托方反馈——"现在的波纹沿一个方向，水面单一化严重"，要求做到《docs/波纹2.jpg》所示效果。
> 板块：物理模型（watersim 浅水仿真）+ 光影渲染（grayview/luxShaders 环境波涛）。

---

## 1. 参考图拆解（波纹2.jpg）

目标观感可拆为四个物理特征：

| 特征               | 图中表现                                     | 现状差距                                                                       |
| ------------------ | -------------------------------------------- | ------------------------------------------------------------------------------ |
| **多方向交叉波列** | 涟漪沿任意方向行进、彼此交叉成网，无主导航向 | 五成分方向虽散（-70°~100°），但大振幅长波集中在 20°/65° 扇区，视觉主导方向明显 |
| **弯曲的波纹线**   | 波纹是弧线、蜿蜒交叉，没有贯穿整域的直线     | 全部是纯正弦平面波 → 无限长直条纹族，交叉感弱                                  |
| **多尺度碎波**     | 长涌之上有大量中短碎波，密度均匀             | 短波振幅占比过小（0.0003~0.0006），被长波淹没                                  |
| **阳光光斑闪烁**   | 波面上随机分布的亮斑（sun glitter）          | GGX 高光已有，但法线场方向单一 → 光斑排列成行而非随机撒布                      |

## 2. 成熟技术调研结论

| 技术               | 来源                                                                                                  | 结论                                                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **多副本异向叠加** | three.js 官方 `Water.js`（`getNoise`，已核对源码）：同一法线贴图以 4 组不同尺度、不同方向速度采样求和 | 业界标准手法——"多方向+多尺度叠加"即打破单一方向的正解。本项目采用同思想，但保持纯解析谱（贴图无法与 TS 镜像逐点一致） |
| **宽方向谱**       | Tessendorf 2001（FFT 海洋）/ GPU Gems 1 Ch.1：真实海面方向谱近各向同性，4~8+ 个成分方向均匀撒开       | 方向应覆盖 360°（含反向传播成分形成真交叉），长波之间夹角要大                                                         |
| **域扭曲**         | Iñigo Quilez "Domain Warping"（shadertoy 大量水面应用）：低频场扭曲高频采样坐标                       | 把直条纹弯成交叉网的最有效手段，一层扭曲即可；约束 ‖∇W‖<1 防坐标折叠                                                  |
| **随机相位**       | 谱合成通识                                                                                            | 多成分同相位会周期性出现"整体对齐"拍纹，每成分固定随机相位可消除                                                      |
| Gerstner 波 / FFT  | GPU Gems / Tessendorf                                                                                 | **不采用**：Gerstner 水平位移会破坏"液滴贴浪"镜像的简单性；FFT 成本与架构不符。总幅仅 ~mm 级，非线性收益低            |

## 3. 方案设计

架构不变：**组件表唯一真源 → GLSL 由 TS 逐项展开生成 + TS `ambientWaveHeight` 高度镜像（液滴贴浪逐点一致）**。三项改动：

### 3.1 波谱重构（AMBIENT_WAVES：5 → 9 成分）

- **方向覆盖 360°**：15°, 150°, -95°, 62°, -38°, 128°, -8°, 96°, -165°。排序后最大方向间隙 70°；两个最长波（0.42/0.34m）夹角 135°，形成强菱形交叉网。
- **波长对数分布** 0.42 → 0.058m（下限不变，256² 网格下 15 顶点/波长，无欠采样）。
- **中短波振幅加权提升**：短碎波不再是长波的零头，碎波密度向参考图靠拢。
- **新增 `phase` 字段**：每成分固定随机相位（0~2π），打破同相对齐拍纹。
- **校准约束**（防破格）：总幅 ≈ 9.3mm（原 7.3mm）、总斜率 Σa·k ≈ 0.32 rad（原 0.24，上界 0.35）；速度区间维持委托方"波浪速度减缓"裁决的 0.28~0.38。

### 3.2 域扭曲（新增 AMBIENT_WARPS 扭曲场）

低频慢变向量场（3 成分正弦对），高频波在其扭曲坐标上求相位：

```
W(p,t) = Σₙ bₙ·dₙ·sin(qₙ)          qₙ = kₙ·(eₙ·p) − ωₙ·t + φₙ
p' = p + W(p,t)
h  = Σₘ aₘ·sin(kₘ·(dₘ·p') − ωₘ·t + φₘ)
```

- 扭曲波长 0.85/0.62/0.45m，位移幅度 0.016/0.011/0.007m，速度 0.22~0.28（慢于波谱，作"流的骨架"）。
- **折叠约束**：‖∇W‖ 峰值 ≈ 0.33 < 1，映射一一对应，无坐标翻转。
- 效果量化：对最短波 λ=0.058m，位移可达 0.58λ → 直条纹显著弯折；对长波仅 0.08λ 轻微蜿蜒。

### 3.3 解析导数（链式法则，保持焦散/法线一致性）

设 ∇W 分量打包 `wg = (∂Wx/∂x, ∂Wx/∂z, ∂Wz/∂x, ∂Wz/∂z)`，∇²W 迹 `wl = (∇²Wx, ∇²Wz)`，M ≡ I + ∇W：

```
∇sₘ   = kₘ·Mᵀdₘ          （Mᵀdᵢ = dᵢ + Σⱼ dⱼ·∂Wⱼ/∂pᵢ）
∇h    = Σₘ aₘ·cos(sₘ)·∇sₘ
∇²h   = Σₘ [ aₘ·cos(sₘ)·kₘ·(dₘ·wl) − aₘ·sin(sₘ)·|∇sₘ|² ]
```

W=0 时严格退化为现行公式（`a·k·d·cos(ph)` 与 `−a·k²·sin(ph)`），符号约定不变。GLSL 与 TS 镜像同表展开，两侧不可单独改数（沿用既有铁律）。

### 3.4 不改动项

- `uWaveAmp` 语义不变：整体幅度倍率（扭曲场在倍率内部，amp=0 时波场全平）。
- GGX roughness 0.09、焦散链路、水面/水底/液滴/液桥材质结构不动；谱加密后法线方向多样性提升，glitter 光斑自然随机化。
- `RENDER_PARAMS.ambientWaveAmp = 1.0` 不动（观感强弱的手感微调入口保留）。
- 液滴贴浪消费点（viewer.ts `lensBottomY`）接口不变。

## 5. 风险与回退

- **观感过强**：总斜率 0.24→0.32，法线更陡、焦散更强。回退入口 = `RENDER_PARAMS.ambientWaveAmp`（0.8 一档即回到旧强度量级），无需改谱。
- **性能**：GLSL 逐顶点/逐片元波场项数 5→12（波 9 + 扭曲 3），纯 ALU，同族 Ocean 实现常规规模；顶点着色器不消费导数输出会被编译器剔除。
- **一致性风险**：TS 镜像与 GLSL 均由同一张表生成/实现，测试覆盖振幅界与生成字面量冒烟，两侧手改数值被测试拦截。
