## 1. 参考图拆解(docs/光纹.jpg)

参考图为经典泳池焦散特写,可拆出四个形态特征:

| 特征 | 图中表现 | 旧实现(∇²h 拉普拉斯)差距 |
| --- | --- | --- |
| **亮网线形态** | 细亮线连成不规则多边形网,网眼大小均匀,线是连续闭合的 | 拉普拉斯正负瓣随波列走,呈「条纹状亮带」而非闭合网眼 |
| **线亮度** | 线芯近白(过曝感),向网眼内部快速衰减 | 亮度随 ∇²h 线性调制,无「细线锐峰」结构 |
| **网眼尺度** | 画面宽约 8~10 个网眼(≈8~10cm/眼) | 波长 5.8~42cm,条纹间距随波长走,尺度不均 |
| **动态** | 网眼缓慢蠕动、线自愈合重组(液透镜阵随波面重聚焦) | 随环境波场移动,方向感强、蠕动感弱 |

## 3. 方案设计

### 3.1 焦散网场 v3(causticWeb:哈希格点 Voronoi 边缘,构造性非周期)

```
g    = (wxz + warp(wxz,t)) / CAUSTIC_CELL      (0.09m 一格;小幅域扭曲弯直轴)
id   = floor(g),  f = fract(g)
3×3 邻域 (i,j) ∈ {−1,0,1}²:
    cid = id + (i,j)
    ha,hb = hash12(cid+7.3), hash12(cid+31.7)   (整数格点哈希 → 非周期按构造)
    pt  = (i,j)+0.5 + (ha,hb−0.5)·0.6           (静态抖动 ±0.30)
        + 0.18·(sin(t·(0.55+0.6hb)+ha·2π),      (双频摆动 ±0.18:边界蠕动/愈合)
                 cos(t·(0.45+0.7ha)+hb·2π))
    维护最近两点 f1≤f2 及其位置 p1,p2
e    = f2 − f1                                   (0 = 中轴边界 = 亮线)
dseg = |p2 − p1|                                  (两翼点距)
glow = 0.45 + 0.55·smoothstep(1.6, 0.6, dseg)     (点距近 → 聚焦强 → 线亮粗)
web  = exp(−e²·600) · glow                        (细亮丝,半宽 ≈ 2-3% 格)
web ×= 0.6+0.4·vnoise(g·0.9 + 慢漂移)             (沿线分段明暗:亮段渐隐到暗段)
web ×= 0.72+0.28·vnoise(wxz·2.3 + 慢漂移)          (大尺度明暗:破均匀复制感)
```

- **世界坐标采样**(非 uv):相机运动时网纹钉在水底,不随屏幕滑动;
- **非周期 = 构造性**:特征点由整数格点哈希给出,任意平移都不重合(哈希值即伪随机,
  无周期结构);v1/v2 的失败根因(全局平移等变场必有重复单元)被从生成器层面根除;
- **动态**:特征点随哈希相位/速度双频摆动 → 中轴蠕动、相邻点易主时边界自愈合
  (参考图"液透镜阵重聚焦");摆动 + 静态抖动 < 0.5 格,3×3 邻域按构造无漏;
- **蜿蜒度**(v3.1,委托方「线条过于几何化」整改):直线中轴经 `causticMeander`
  多成分正弦域位移弯成蜿蜒线——位移手法取自 Hoskins 场的蜿蜒来源(迭代 sin/cos
  域位移,前置到格点查询之前),谱结构取自深夜荧光海岸 `coastDist` 蜿蜒谱同款
  (λ 0.55/0.32/0.19m,幅 30/14/6mm 随波长递减,相位慢漂移 0.17-0.31 rad/s →
  蜿蜒随时间缓变);折叠约束 ‖∇warp‖ = Σ2πA/L ≈ 0.82 < 1,映射一一对应无翻转
  (luxCaustic.test.ts 解析常量守护);
- **纯 GPU 层**:与 nightCoast 同纪律(第九批),无 TS 镜像同步约束,测试走 GLSL 冒烟
  (守护哈希格点结构 + 全局周期缩放/旋向残留确删);
- **纯 ALU**:9 邻域 hash + 少量三角函数/像素,零纹理零 RT(实测 120fps 无回退)。

### 3.2 时段语义(删除/替换的精确边界)

| 时段 | 旧光纹(∇²h×causticScale) | 新行为 |
| --- | --- | --- |
| 清晨/正午/傍晚 | **删除**(委托方指令) | 焦散网:强度 = causticScale(0.45/1.35/0.7,预设真源不变) |
| 深夜 | 0.1 残留 | **焦散网关断**(`×(1−uNightDots)`):第九批裁决「深夜水底亮度只允许来自荧光海岸」,顺带清掉旧残留;荧光海岸不动 |

causticScale 语义从「∇²h 聚焦强度」改为「焦散网强度」,数值表与
presets.test.ts 排序断言(noon 最大、其余 < noon)不变。

### 3.3 光照合成(与阴影/荧光的次序)

```
gate = uCausticScale · (1−uNightDots) · shadow
web  = pow(双层合并场, 1.5)                     (显示链提锐:收窄 ACES 展宽的亮核)
ca   = web · gate
col  = col · (1 + ca·CAUSTIC_MULT − 暗隙让光(CAUSTIC_GAP·gate)) + uSunColor·(ca·CAUSTIC_ADD)
```

- **乘法路**提亮底色,**暗隙项**按能量守恒让光(光聚进亮线 → 网眼变暗,参考图
  网眼中蓝;对应旧 ∇²h 实现正瓣提亮/负瓣压暗的对偶结构),**加法路**给线芯日光色
  (正午白/清晨暖金/傍晚琥珀——随 uSunColor 自时段化,参考图线芯近白过曝感);
- 合成放在 dropShadowField 之后、nightCoast 之前(深夜网关断,次序无观察差);
- 两个消费点同函数:**折射视图** `shadeBottom`(透过水面/液滴看)+ **水底直视**
  `LUX_BOTTOM_FRAG`,保证三层同一网纹(旧焦散的同构纪律)。

### 3.4 删除项(∇²h 光纹链路的日间消费)

- `shadeBottom` 与 `LUX_BOTTOM_FRAG` 的 `clamp(lap·uCausticScale·CAUSTIC_GAIN, −0.8, 3.0)`
  及正负瓣调制(`(1+max(ca,0)·2)` / `1+min(ca,0)`)整体移除;
- `CAUSTIC_GAIN 0.03` 宏移除,换 CAUSTIC_TILE/CAUSTIC_MULT/CAUSTIC_ADD;
- `shadeBottom(uv,wxz)` 签名收窄为 `shadeBottom(wxz)`(uv 参数只为旧 heightDerivs 服务);
- `waterDerivs` 的 lap 输出保留(水面法线/折射仍用 slope;lap 变为可被编译器剔除的死输出,
  架构不动)。

### 3.5 不改动项

- 水面材质结构/折射/Fresnel/GGX/环境波涛谱(AMBIENT_WAVES/WARPS)/液滴贴浪镜像;
- 液滴软影、深夜荧光海岸(coastDist/nightCoast 及其测试)、上方雾气层;
- viewer.ts uniforms 接线(uCausticScale 已有时段渐变,零改动);
- 物理与交互零改动(铁律)。

### 3.5 v4 现行实现(原型 index-wave.html「迭代折射焦散 + 去平铺三件套」原样移植)

委托方提供 `实例.png`(= 原型已验收的水面焦散观感:细软蜿蜒亮丝、无重复单元)并
裁决采用——原型框架与本项目完全一致(Hoskins 迭代核 + 世界/模式坐标程序化采样)。

```
焦散核 causticWeb(uv,t)(原型同名函数):
    p = mod(uv·2π, 2π) − 250          (mod+(-250) 是本技法数值区间的必要部分,不可省)
    5 次迭代:i = p + (cos(tₙ−i.x)+sin(tₙ+i.y), sin(tₙ−i.y)+cos(tₙ+i.x))
    c += 1/|(p.x/(sin(i.x+tₙ)/inten), p.y/(cos(i.y+tₙ)/inten))|
    返回 clamp(|1.17 − (c/5)^1.4|^11, 0, 1)     (pow 11 细丝锐化,底数 abs 先行)

去平铺三件套(消除重复单元的正解,原型已验收):
①域扭曲 warpP:慢变大尺度摆动(WARP_AMP 0.3),把瓷砖直边揉成水波曲线;
②双采样融合 aperiodicWeb:同层两个大偏移副本(一旋转 30°)用慢变遮罩
  m = 0.5+0.5·sin·sin 做 mix(w1,w2,m) —— 接缝互相遮盖 → 周期性不可见;
③主/次层 seed 独立(相位/偏移/遮罩各自独立),次层反向慢漂(×0.7),疏密两节奏。

合成(原型 sceneColor 焦散段):
    wp = wxz + drift·uTime                   (光网整体漂移 0.006/−0.004 m/s)
    web  = aperiodicWeb(wp·3.4,  t·0.5, 0.0)          (主层:胞径≈1/3.4 m)
    web2 = aperiodicWeb(wp·1.9+13, −t·0.35+7, 5.0)    (次层:更疏更淡,加深度)
    patchFade = 1 − 0.34·(0.5+0.5·sin·sin)            (斑驳:局部涟漪隐没,更疏更自然)
    ca = (min(web·0.10, 0.14) + min(web2·0.08, 0.084)) · patchFade
    col += uSunColor · ca · uCausticScale · (1−uNightDots) · shadow
```

- **与原型的两处本地化差异**:①采样域 = 世界坐标 wxz(网纹钉在水底,不随相机滑动);
  ②加光走 uSunColor 时段色(正午白/清晨暖金/傍晚琥珀;原型为纯白);
- **沿用项**:夜间 uNightDots 关断(第九批:深夜亮度只允许来自荧光海岸)、
  液滴影吃光、三消费面同函数(水底直视 + 水面折射 + 液滴折射);
- **移植时踩坑**(交接 §9 同款教训再验证):①`patch` 是 GLSL ES 保留字(本项目
  编译器拒绝;原型内合法)→ 改名 `patchFade`,顺带修掉第八批雾层同名的静默隐患
  (改名 `billowMask`);②原型 `npx.y` 对应本项目 `wxz.y`(vec2 的 y 即世界 z)。
- **调参入口**:luxShaders 头部 `CAUSTIC_SCALE/SCALE2`(密度)、`CAUSTIC_SPEED`
  (演化速度)、`CAUSTIC_AMP/AMP2/CLAMP`(浓度/防过曝)、`CAUSTIC_WARP`(蜿蜒度)、
  `CAUSTIC_PATCH`(斑驳)、`CAUSTIC_DRIFT`(整体漂移)——与原型 CONFIG 一一对应。

## 5. 风险与回退

- **过曝/过弱**:入口 = luxShaders 头部 `CAUSTIC_MULT/CAUSTIC_ADD/GAP`(线亮度与暗隙)、
  `CAUSTIC_CELL/WOBBLE`(网眼尺度与摆动幅度;WOBBLE+静态抖动须 <0.5,测试守护)、
  预设 `causticScale`(时段强度,既有真源)。
- **性能**:9 邻域哈希 + 少量三角函数 × 三消费面(水底/水面折射/液滴折射),纯 ALU;
  实测 120fps 无回退。若低端设备不足,首砍域扭曲与沿线明暗两路 vnoise(形态代价最小)。
- **GLSL 兼容**:循环常量界、无依赖纹理、ES1.00 全兼容;`hash12/f1,f2` 分支维护与
  nightCoast 同族(项目内已验证);`pow` 底数恒正(clamp/smoothstep 先行,交接 §5-7 红线)。
- **深夜回归风险**:网纹被 uNightDots 硬关断,荧光海岸路径字节级未动;
  luxNight.test.ts 全量保留守护。
- **平铺回归风险**:v3 按构造非周期;`luxCaustic.test.ts` 守护「整数格点哈希 + floor
  格点」结构与「全局周期缩放/旋向(causticLayer/CAUSTIC_TILE/v2 旋转矩阵)确删」,
  防止后续调参把平移等变场引回来。

## 6. 相似度判定(截图对比;过程截图与参考图 `光纹.jpg` 已于 2026-09-10 整理时删除)

> 方法:`npm run dev` → `/luxview.html` 逐时段截图,与参考图按四特征
> (§1:网线形态/线亮度/网眼尺度/动态)逐条比对;不足则回步骤 3 换技术。
> **本节文字结论为唯一留存记录**(截图/参考图见 git 历史整理前的最后一次提交)。

**v1(单层 Hoskins 改制,已废弃)**:网眼 ~25cm 过大(查因:Hoskins 场一周期 ~3 网眼)+ 加法路
× 太阳 HDR 强度致线芯糊开 → 收 TILE、ADD,增暗隙与提锐后人验通过;但委托方人工核验判
**规律性/复制粘贴感**不合格(单层场 2π 天然周期被世界坐标采样暴露)→ 回步骤 3。

**v2(双层异尺度异旋向去平铺,已废弃)**:周期比 1.625 非整数 + 旋向差 63.4° + 异速,
静态自检通过;委托方人工核验**仍见重复单元**。重析根因:两层各自仍是全局周期场
(平移等变),max 叠加不消除单层周期性——叠加式去平铺对程序化连续场不成立,必须换
构造性非周期生成器 → 回步骤 3。

**v3(哈希格点 Voronoi 边缘场,静态自检通过)**:

| 时段 | 网线形态 | 线亮度 | 网眼尺度 | 动态 | 结论 |
