### 迭代记录(证据帧抓到,1 项,已整改)

1. **「带暗边的小珠」**:初版廓线「宽 alpha(`smoothstep(1,0.65)`) + 细 core(`pow(1-rl,2.4)`)」
   —— alpha 廓线宽于颜色廓线 → 边缘把背景压暗成**暗环**,圆盘内芯又是不透明块 →
   整颗读作**小珠子**(正是委托方要否掉的东西)。
   整改:**rgb 与 alpha 取同一条两瓣廓线** `fall = 0.55(1−rl)^5 + 0.45(1−rl)^1.6`
   (细亮核 + 宽淡晕),常数亮色 > 背景 → 任何半径**只亮不暗**;重取帧后成立 ✅。

## 3. 与方案的偏差(以代码为准)

1. 日间色由 `vec3(1.0,0.97,0.90)*1.5` 微调为 `vec3(1.0,0.95,0.85)*1.5`(更暖一点,读「光」不读「瓷」)。
2. 廓线由「core/edge 两参数」改为**单一两瓣廓线**(§2 迭代记录)——
   这不是调参而是**正确性修正**(分廓必然产生暗环)。
3. 爆散段粒径随物种一起下调(0.009→0.005);数量/曲线/时序**未动**。

## 4. 已知边界与遗留

1. 白天水面偏亮(整帧均值 ~155/255):光点靠**亮度越 bloom 阈值(0.7)出晕**读作「光」;
   若委托方觉得日间仍不够「发光」,首选抬核亮度(**不**改 add 混合 —— 夜闪纪律)。
2. 光点仍不带物理(不搅动水面),与既有边界一致。
3. 直播运动质量仍以「序列静帧 + 运动学单测」佐证,**非录屏**;委托方实况为准。
4. 其余未尽事项(A-2 粗细映射 / 副本去留 / 夜闪回灌 / 文字两边界 / 小变化演出)不变。
