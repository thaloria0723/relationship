### 第五批裁决(委托方聚焦三需求引申)

- **编舞期守护**:聚焦期与退场编舞期,组相关桥 `guardSlot=1`(不张力/不断桥/
  不复检侵入)、成桥扫描全局面冻(`formationFrozen`)、组内滴 `intruderExempt=1`
  (悬浮/旋转/回场飞行的 2D 投影不作无关桥的侵入第三方)。无守护时中心滴退出
  即转空中段,spoke 会被「端点失效」规则立即永久断桥——「暂时断裂恢复」无从谈起。
- **断桥恢复时机 = 编舞收尾**(非退出瞬间):成员曲线归位与网络张力恢复同步,
  避免拉伸桥把组外端拽离原位;语义序列与需求③一致(回位 → 恢复)。
- **等长化只外推不内拉**:L = max(各 spoke 当前距, 持距下限),成员经
  `focusOrbitRadialK` 一阶收敛到 L(不用桥张力推——编舞期张力已被守护关闭,
  轨道速度是唯一驱动;悬浮段 exp(−4dt) 使有效角速率 = ω×0.975)。
- **退场曲线**:水平二次贝塞尔(控制点=弦中点+顺轨道切向垂直偏移,顺势螺旋)+
  垂直 u² 缓入(衔接落水加速观感);落水经弹坑通道溅落;重进聚焦时
  `forceFinalizeFocus` 强制收尾(未完成曲线的成员就地归位锚点)。
- **聚焦相机**:视点 = 中心滴悬浮位(屏幕正中,X 轴像素级;Y 向 ±7px 为涟漪
  波面起伏);高度 h = (L+maxR+focusFitMargin)/tan(min(半垂直FOV,半水平FOV))×1.12,
  俯角偏移 0.12h;退出恢复进入前视角。
- 新参数:focusOrbitOmega 0.4 / focusOrbitRadialK 3 / focusRipplePeriod 0.45 /
  focusRippleVolume 4e-6 / focusReturnDur 1.0 / focusFitMargin 0.035(均入范围表)。

### 第四批新裁决(委托方明示)

- **液滴尺寸恒定**:液滴落下(入水成漂浮态)后大小不再变化——拉普拉斯压差流动整体移除,`bridgeFlowK` 参数删除,桥内流动粒子删除。液桥语义 = 关系网的边,只连接、不搬运体积(与第三批「连接而非毛细作用」裁决同向)。⚠ `物理模型实施文档-2026-09-06.md` 中拉普拉斯流动小节待计划会话同步修订。
- **悬停自运动补偿**(抖动主根因修复):悬停退出带 = `1.6×(cr+14) + |当前屏幕圆心 − 进入时圆心|`。升力抬升的屏幕像素幅度随液滴大小/变焦变化(默认视距 16–43px),固定倍率滞后覆盖不了 → 圆缘下方指针陷入「抬升→退出→回落→再进入」极限环;自运动补偿按构造保证「液滴自己动不触发退出」,指针真正离开才退出。
- **贴水随动** `zFollowTau=0.1s`(范围 [0,0.5],0=硬贴):浮态 z 朝「总高+(R−d)」一阶低通,抑制悬停涟漪泵(~9Hz,1.31mm p-p)与入水高频纹波跟随,稳态颤动 ≤0.8mm(实测 0.25mm);升力浮出与慢波 riding 不受影响。

### 第三批新裁决(委托方明示)

- **连接语义**(委托方原话要义:液桥=关系网的边,重点是连接而非毛细作用):
  - 成桥**距离无关**——任意两漂浮滴(冷却完毕/未成桥/桥轴无第三方占据)持续 drainTime 即成桥;`bridgeRange` 仅剩近接触窗口语义(pairs.ts 碰撞抑制/聚合计时)。
  - `restLen = max(成桥距, rSum·(1+bridgeRestGap))`,`bridgeRestGap=1.0` → 靠得太近的对被推开到**净间距 ≥1.0·rSum**(每对漂浮滴之间都有桥持距 = 「间距过小」的根治)。
  - **拉伸不断裂**:`bridgeBreakStretch` 参数已删除;断桥唯一途径 = 侵入治理(胶囊排斥 + 0.2s 复检 + 交换删除重映射)。断桥同时清 pending(距离门槛取消后须显式清,否则冷却结束瞬间重桥)。
  - 重锚定释放时 `rebaseRestLengths(i)`:桥 restLen 重定为当前距(距离变化被连接吸收,牵连端不被拖向旧距离)。
  - 桥池容量 = n(n−1)/2(完全图边数);viewer `bridgeMax` 同步。
- **拖拽分层阻力**:拖拽期桥张力**单侧出力**(被拖端零阻力,手感同无桥);**牵连位移圈** `dragAnchorShift=0.005m`——拖拽期间未被拖的漂浮滴离出生锚点超 5mm 即位置投影回圈 + 削外向径向速度(位置级硬约束,勿改回弹簧对抗弹簧方案——桥 K=4 N/m 远硬于锚定弹簧,准静态平衡会把牵连端拉走)。
- **悬停滞后**:控制器悬停退出容差 = 进入容差 ×1.6(`HOVER_EXIT_EXPAND`);根因是升力抬升移动屏幕圆导致命中态帧率级翻转。物理侧守门:持续悬停稳态 z 波动 ≤2mm(测试)。
- 桥渲染:表面到表面(两端内嵌 0.75r)、端径 0.36·r(大滴端更粗)、颈径 0.30·min(r)、拉伸变细 ×√(restLen/dist) clamp [0.5, 1.25]。
- 拖拽释放双模式收紧:弹回**出生锚点**(非抓取位);重锚定须 held ≥1s **且** moved ≥0.15m(AND)。
- 漂移治理:`driftDamping=2.5` s⁻¹(风格化,物理 Stokes 仅 ~0.05)+ `homeK=4` s⁻² 落点回位弹簧(始终朝出生锚点)+ `pinRadius` 0.06→0.03;坡度响应保留但漂移有界(<pinRadius)、波停回位(<4mm)。
