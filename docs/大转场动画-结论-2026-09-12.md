### 相似度迭代记录(判据未达 → 回看方案再整改,共 3 项)

1. **巨滴长成窗**:初版放在汇聚段,巨滴中途吞掉滑入中的旧滴,「汇聚」读不出
   (t0.8 帧实测)→ 长成窗移到过渡段前半(merge[0]-0.12 → merge[0]+0.35),
   悬停段全程保持巨滴。附单测守护(`during(0.8).scale < 1.3`)。
2. **过渡段泛白**:bloom 增辉 1.1 过猛,整帧 washed-out(夜闪纪律红线)→
   降到 0.45,蓄力 flash 0.22→0.1。整改后水面纹理可见、辉光只在巨滴周缘。
3. **火花圆环感**:48 颗同步同距 → 读成规整圆环而非炸裂 → 方位散布 ±1.3rad、
   半径抖动 0.55~1.45×、飞射时长 ±20% 个体错峰。整改后散布自然。

## 4. 已知边界与遗留

1. **编排与物理解耦**:汇聚段旧滴的滑入是**渲染侧偏移**(引擎位不动,波场不跟滚);
   真实落水涟漪只在爆散 spawn 时产生。要「汇聚也搅动水面」需引擎级力场,另议。
2. **火花不做拉伸**(「拉长」由新桥抽丝承担);火花是廉价珠光材质,不带折射焦散。
3. 滑块章节 ≠ 真实章节数据( fixture 三章;真实数据接入按清单 A-5/C 组字段)。
4. 生产回灌未决项不变:夜闪修复、(新增)大转折整套、文字 v3 —— 均只在副本。
5. `fx=9` 直播(非取帧)从空场起播:旧网落定 ≈0.3s 与 t=0 略重叠,重播(空格)
   无此问题;取帧路径不受影响(预滚后才开始)。
