## 0. 背景与定位

- 视觉系统按 模块①物理 / 模块②交互 / 模块③光影渲染 三模块拆分(视觉规格 §1)。①②已完成:`web/src/watersim/`(水体物理引擎)+ `web/src/interaction/`(意图状态机),灰模查看器 `web/src/grayview/viewer.ts` 是全工程**唯一 import three 的文件**。

## 1. 目标与验收形式

> **版本一验收 = luxview.html 网页观感**:液面/液滴/液桥呈现水的材质(透明、折射、镜面高光、水下焦散);液滴较深、液桥极度淡化(透明度 30%);悬停/点击某液滴时仅该滴出发的液桥变亮加粗;聚焦模式默认高亮全部中心直连桥;四时段一键切换,观感逐条符合委托方描述(§2-b)。

非目标(本版本禁止):屏幕空间折射/反射(抓帧 RT)、阴影贴图、PBR transmission 全管线、体积光/God rays、粒子飞溅、昼夜连续插值(v2 预留,预设已参数化)、移动端。

## 2. 需求词表 → 光学机制映射

### 2.1 委托方需求 a(材质与高亮语义)

| 词 | 光学/渲染机制 |
| --- | --- |
| **液面/液滴/液桥都按水的材质** | 三者同一套水光学:Fresnel 反射(F0=0.02)+ Snell 折射(n=1.33)+ 镜面高光(GGX)+ 水体吸收。差异只在几何与光程 |
| **液滴颜色较深** | 水球=透镜+全反射腔:内光程长、吸收强,正入射透射率高(看得进但暗)。渲染:内体色 ×`dropletDarken`(0.5,风格化量化「较深」) |
| **液桥极度淡化(透明度 30%)** | 细水柱光程短 → 极透明。`bridgeOpacity = 0.30`(委托方指定值),Fresnel 边缘亮线保留 |
| **悬停或点击液滴 → 仅该滴出发的桥高亮(变亮加粗),其余不变** | 渲染层高亮策略(§8):激活滴=悬停目标或拖拽目标;高亮=透明度 0.30→0.78 + 颜色提亮 + 半径 ×1.6;其余桥逐字节不变 |
| **聚焦模式默认高亮中心滴相连的全部桥** | 聚焦期 spoke(中心直连桥)高亮因子 = 1(引擎 `getFocusCenter`);非 spoke 组桥已被引擎切断不渲染,组外桥不渲染变化 |

## 3. 物理规律与风格化声明(渲染贴合物理的边界)

**严格按物理**(不随预设改变的常量):

- **Fresnel(Schlick 近似)**:F = F0 + (1−F0)(1−cosθ)⁵,F0 = ((n−1)/(n+1))²,n=1.33 → **0.02**。正入射反射 ~2%(看得进水底),掠入射 →1(镜面)。这是「水面像镜子、近处看进水里」的物理根源,不参数化。
- **Snell 折射**:视线穿水面一次折射(η=1/1.33),折射线与池底平面解析求交 → 底纹采样点。波面斜率使折射点抖动 → 水底纹路晃动。
- **Beer–Lambert 吸收**:T = exp(−σ_a·L),红光衰减最快 → 水体蓝绿。
- **GGX 镜面高光**:波面斜率分布 → 太阳/月亮 glitter;正午垂直入射高光分散成面,清晨/傍晚低角度拉成光路。
- **焦散**:波面=透镜阵,聚焦度 ∝ 高度场拉普拉斯 ∇²h(凹面聚焦/凸面发散,液滴凹陷核=碗形 → 自动产生「亮环+中心暗斑」,与真实水滴光影一致)。由高度纹理片元级 5 tap 解析计算,零额外 CPU。
- **高度雾**:雾因子 = 1−exp(−d·ρ_mist·noise(xz,t)·e^(−k·y)),d 为视距、y 为高度;雾是流体 → 低频噪声漂移。

**声明为风格化**(物理量级放大/点化,与模块①毛细吸引同类声明):

- `waterAbsorb = (2.2, 0.75, 0.45) /m`:真实 5cm 浅水几乎无色,放大吸收使水体蓝绿可读。
- `poolDepth = 0.14 m`:视觉池深(物理流动层 H=0.05 是另一回事,不混用)。
- 夜晚金色光点:月光焦散的点化+金色化(委托方明示要求)。
- 液滴 `dropletDarken`、桥 30% 透明:委托方指定观感值。

```

├── presets.ts               四时段光系预设 + 渲染参数(本模块唯一常量真源)

```

数据流(渲染只读,零物理改动):

```
引擎快照(高度场 bakeTotalInto / 液滴 r,eps,z / 桥 a,b,cut,restLen)
  + 控制器状态(hover/drag 目标) + 引擎焦点态(getFocusCenter)
→ lighting.presets(时段 → 光系 uniforms,0.45s 一阶渐变过渡)
→ lighting.emphasis(桥槽位 → 高亮因子,viewer 每帧向目标值平滑)
→ viewer GLSL:水面 / 水底 / 液滴 / 液桥 四材质 + bloom 后期 → 屏幕
```

**铁律(继承视觉规格 §1)**:

1. `lighting/` 不 import three、不挂 DOM、纯数据+纯函数;
2. `viewer.ts` 仍是全工程唯一 import three 的文件;
3. 模块③不产生任何物理副作用(不写引擎状态);
4. 渲染参数真源 = `lighting/presets.ts`,物理参数真源仍是 `watersim/params.ts`(只读)。

## 5. 渲染管线(着色器设计)

### 5.1 高度场纹理(渲染与物理同源)

每渲染帧 `field.bakeTotalInto(buf)`(已有,= 动态 h + 准静态凹陷核)上传为 `DataTexture`(R32F,N×N,Nearest——256 格对应 ~1px,无块感;启动探测 float-linear 扩展,可用则 Linear)。顶点着色器按格心精确采样做位移;片元着色器 5 tap 同时得**法线**(中心差分)与**拉普拉斯**(焦散),逐像素法线比 CPU 法线更细腻,零额外 CPU。

### 5.2 水面(核心材质)

```
F = fresnel(N·V, F0=0.02)
反射:程序化天空梯度 mix(horizon, zenith, R.y^0.5) + 太阳/月亮圆盘辉光
折射:refract(−V, N, 1/1.33) 与池底平面求交 → shadeBottom(折射点)
水体:透过率 = exp(−waterAbsorb·光程),内散射 = waterBody(风格化蓝绿)
高光:sunColor · GGX(roughness 0.09) · glintGain
末段:饱和度/对比 grade + 雾
```

### 5.3 水底(池底平面,`shadeBottom` 与水面折射共享同一 GLSL 函数)

- 基色 = albedo × (太阳直射·max(sunDir.y,0) + 半球环境);
- 焦散 = clamp(∇²h · causticScale·poolDepth 因子, −0.8, 3.0);
- 液滴软影:uniform 数组(≤maxDroplets 组位置/半径)解析软斑,强度按预设(正午最重);
- 夜晚金色光点:世界坐标点阵(cell 0.05m,cell 内哈希偏移单点),亮度 = 点形 × 焦散场(→波纹状分布)× 时间闪烁(→闪烁)。

### 5.4 液滴(InstancedMesh 自定义着色器)

`instanceMatrix` + 实例属性 `aEps`(y 压扁法线修正:n.y /= (1−ε))+ `instanceColor`(聚焦压暗/提亮,沿用灰模语义)。片元 = 内体色×`dropletDarken`×(1−F) + 环境反射×F + GGX 高光 + Fresnel 边缘亮线。不透明。

### 5.5 液桥(透明,委托方 30%)

沿用 CPU 颈状管顶点(表面到表面跨距/端径 0.36r/颈 0.30·min(r)/拉伸变细),新增每槽位实例属性 `aEmph`(高亮因子,viewer 平滑)。片元:alpha = mix(0.30, 0.78, emph),颜色随 emph 提亮;顶点半径 ×(1 + 0.6·emph)(加粗)。depthWrite 关、renderOrder 最后。

### 5.6 后期与色调

- `EffectComposer = RenderPass + UnrealBloomPass + OutputPass`(bloom 按 §3-6 预设「按需一个 Pass」加;傍晚辉光 0.65 最强,深夜 0.30,清晨 0.12,正午 0.08);
- tone mapping = ACESFilmic,曝光按预设;饱和度/对比在材质末段 grade chunk(傍晚对比 1.12、正午饱和 1.15);
- 场景背景色按预设(傍晚=金橙与海军蓝之间,深夜=近黑)。

## 8. 高亮策略(emphasis.ts,纯函数)

```
computeBridgeEmphasis(query, out):
  每桥槽位 k ∈ [0, count):
    cut[k] ≠ 0                          → 0(不渲染,viewer 跳过)
    focusCenter ≥ 0:a|b == focusCenter  → 1(聚焦:中心直连桥全高亮)
    否则 activeDroplet ≥ 0(悬停或拖拽)  :a|b == activeDroplet → 1,其余 0
    无激活                               → 0(全部不变)
```

- 「点击」= 拖拽(引擎语义:按下即 dragStart),故激活滴 = 拖拽目标优先,否则悬停目标——悬停或点击两态同策略;
- viewer 每帧 `emphCur += (target − emphCur)·(1−e^(−dt/0.12))` 平滑,高亮呼吸感而不闪烁;
- 聚焦期控制器不发悬停意图(模块②守卫),spoke 高亮稳定保持;
- 本策略零渲染属性,输入输出均为抽象数组 → 模块②同款可测性。

## 12. 风险与对策

| 风险 | 对策 |
| --- | --- |
| float 纹理线性过滤不可用(部分 GPU) | 启动探测 OES_texture_float_linear;缺失降级 Nearest(256 格 ≈1px,无可感差异) |
| 焦散 firefly(高频拉普拉斯爆点) | clamp(−0.8, 3.0) + bloom 阈值隔离 |
| 透明液桥排序伪影 | depthWrite 关 + renderOrder 最后 + 正常混合;桥间重叠少(细颈) |
| InstancedMesh + 自定义着色器 instanceColor 未创建 | 挂载时对全部实例 setColorAt 预建缓冲 |
| bloom 改变色彩空间 | OutputPass 统一承担 tone mapping 与 sRGB 转换(three 0.185 惯例) |
| 时段切换瞬间跳变 | uniforms 一阶渐变(τ=0.45s) |
