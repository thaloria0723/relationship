# 设计评审：液滴"嵌入感"缺失诊断与最优解

日期：2026-09-04 · 对象：`index-wave.html` 单颗试验滴 · 状态：**只分析，未做改动**

对照基准：水滴2.jpg 参考 + 用户要求（同色系/嵌入感/微微起伏/折射压缩偏移）+ 动效设计文档

## 一、视觉证据

放大裁片（review-crop.png，340×340）与亮度剖面（穿过液滴中心的水平线，背景亮度 ≈218）：

| 位置（相对滴心） | 亮度 | 归属 |
|---|---|---|
| -106 ~ -100px | **253** | 白圈（向光侧，接近饱和） |
| -94 ~ -88px | **187** | 黑圈（向光侧，-15%） |
| -76 ~ +56px | 194→249→205 | 滴内（下部有折射纹理 ✓） |
| +50px | **176** | 滴内暗缘（rimD+边缘吸收） |
| +62 ~ +68px | **255（溢出）** | 白圈（背光侧，完全饱和） |
| +74px 以外 | 218~224 | 背景 |

**结论：黑圈与白圈都是 `lightField()` 散度明暗画的**——负散度钳制(-0.15) = 黑圈，正散度钳制(+0.16)在 220 的底色上直接溢出 = 白圈。宽度各约 12-18px，环绕整周。

## 二、诊断：为什么"割裂"

**贴纸语言的三个特征，恰好全部命中：**

1. **径向对称的环形描边**——真实嵌入的液滴周围没有一圈均匀的明暗环。弯月面的光学效果在向光侧是一条极细的亮线，在背光侧是一小片柔和暗部，**不对称**才对。我们的高斯凹槽是径向对称的，它的导数（散度）天然产出对称的"暗环+亮环"。
2. **饱和白描边**——+0.16 的正亮化叠加在 220 底色上溢出到 255，形成纯白轮廓线。纯白描边是"贴纸/徽章"的视觉语言；真实弯月面亮线应带环境色且从不饱和。
3. **内外光网不连续**——液滴边缘处折射偏移量虽然趋于零（接触线斜率为零），但 `lensDepth=3.2` 恒定放大使中带（d≈0.6-0.95）的采样点跳到 1-1.4 个半径之外：眼睛沿一条焦散细丝从外部走进滴内时，细丝在边缘带"断掉"再在别处出现。**嵌入感的核心证据本是"光网穿过液滴时连续可跟随"**，当前恰恰在这里断裂。

## 三、最优解（按优先级）

### Must Fix

**M1 删除正亮化（白圈直接来源）**
`lightField` 正散度钳制 +0.16 → 0 或 ≤0.04。dome 聚焦的亮斑物理上出现在**滴内折射**中（已实现，效果已被认可），滴外亮环不物理、纯多余。

**M2 暗环改为"背光新月"**
暗化不再全周分布：只在背光扇区（偏离光源方向 ±90°）出现，宽度收到接触线旁 ≤0.1r，向光侧衰减为 0。真实接触影是新月形，不是环形。实现：现有方向权重 w 从 `mix(0.40,1.0,…)` 改为乘法扇区遮罩（背光 1.0 / 向光 0.0，smoothstep 过渡），并收紧 meniscus 宽度系数（90 → ~160）。

### Should Fix

**S1 折射深度渐进（"同一片水"的关键证据）**
`lensDepth` 从恒定 3.2 改为 `LENS_DEPTH * smoothstep(0.15, 0.92, dr)`：接触线带（d>0.92）采样几乎原地 → 滴内外光网**连续衔接**；越往中心水深越大 → 强扭曲与放大集中在滴内中部。这样眼睛能沿着一条焦散丝从外面"流进"液滴里。

**S2 向光侧接触亮线（替代白圈的正确形态）**
细 SDF 亮线（d∈[0.99,1.045]，宽 ~0.05r），只出现在向光侧扇区，颜色取**环境色调**（天光青 #DCEBF4 系）而非纯白加法，强度随局部焦散亮度 env。这是真实弯月面"聚光线"，宽度和亮度都远小于现在的白圈。

### Could Improve

**C1 绕流切向分量**：外部波纹在液滴附近的偏折加一点切向分量（当前纯径向），产生"水流绕过石头"的绕行轨迹，进一步消除同心感。
**C2 色散**：RGB 三通道折射深度微差（±2%），液滴边缘出现极淡彩边（水滴2 参考里可见），加一步即可。

## 四、做得好的（保留不动）

- 滴内 Snell 折射 + 对比增强：已被认可（"水滴内部好多了"）
- 连续高度场架构：dome+弯月面解析场是对的底层，问题只在散度明暗的**表达方式**（对称环形），不在架构本身
- 去平铺波场、按位置受光（env 调制）：均为正确方向

## 五、预期

M1+M2 落地后：外圈只剩"背光侧一小片柔和暗部 + 向光侧一条细亮线"，不再有完整环形描边。S1 落地后：光网穿过液滴连续可跟随，"液滴是水面的一部分"由视觉连续性直接成立。四项全部落地预计一次迭代内可达"嵌入"目标。
