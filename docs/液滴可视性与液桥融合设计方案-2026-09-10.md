# 液滴可视性与液桥融合设计方案 · 2026-09-10(第十一批)

> 委托方任务(五项):①解决液滴可视程度低(尤其清晨/正午),白天三时段液滴材质
> 参照 `实例.png`(珍珠乳白小球;水面层颜色必要时可改);②液桥向内伸入液滴并隐藏
> 内部段,交界面曲面化融合;③深夜液滴改发光小球(暖黄自发光光晕)+ 液桥暖黄边界线;
> ④液滴折射扭曲放大水底光纹;⑤傍晚水底颜色改米白(偏米色)。
> 基线:第十批(焦散网 v4,HEAD `56ef7ff`)。实机现状(2026-09-10 截图核验):
> 清晨液滴几乎完全隐形(粉紫雾洗白)、正午只剩暗色小点、傍晚勉强可见、深夜完全隐没
> ——根因 = 液滴材质与液面同一套「透明水」公式(alpha 0.15~0.7 + uTint 洗色),
> 自身不发光、无轮廓对比。

## 2. 实例.png 液滴观感拆解(白天材质验收基准)

乳白珍珠小球,五要素:
1. **整体奶白偏蓝、不透明感强**,亮度高于周围水面(对比清晰);
2. **蓝色核心**(球心区域偏蓝,奶白壳包边);
3. **亮部高光**(受光侧白色亮斑,柔边);
4. **底部接触亮环**(贴水缘一圈亮环,略外溢到水面);
5. **柔和投影**(现有 dropShadowField 承担)。

## 3. 实施方案

### 3-1 任务① 白天珍珠材质(LUX_DROPLET_FRAG 重写)

- **奶白体**:milk = mix(奶白基色, uTint×1.25, uTintAmt×0.45) × (0.55+0.45·ndl) × 1.35
  —— uTint/uTintAmt 已时段化 → 清晨粉白 / 正午蓝白 / 傍晚亮白自动适配;
- **体合成**:body = mix(透镜折射水底(任务④), milk, 0.55) → 珍珠壳内可见放大光纹;
- **边缘**:Fresnel 天空反射(保留);**高光**:GGX(rough 0.14)×uGlint + 宽域柔光;
- **接触亮环**:ringsm = smoothstep(0.28, 0.03, vLocalY)(vLocalY=单位几何高度,
  0=底缘)→ 加 milk×1.4 + uSunColor×0.15;
- **不透明度**:alpha = mix(0.66, 0.94, F)(旧 mix(0.15, 0.7, F) 是隐形根因);
- **水面接触环带**:`dropRingGlow(wxz)` 加入 shadeBottom(水底直视+水面折射+液滴透镜
  三消费面共享):环绕液滴足迹 r×1.22 处高斯亮环;日间 = uSunColor×0.16 + 微白,
  夜间 mix 到暖黄(夜间液滴是光源)。
- **正午水面微调**(委托方许可「水面层可更改颜色」):surfaceTintAmt 0.55→0.68,
  水面更蓝一档,奶白球对比更强。

### 3-2 任务② 液桥伸入 + 曲面化融合(viewer.ts syncBridges + 桥 shader)

- `BRIDGE_TIP_FRAC 0.866`(恰在表面)改为双常量:
  `BRIDGE_TIP_SURF_FRAC = 0.866`(表面交点,解析值不变)+ `BRIDGE_TIP_DEEP_FRAC = 0.5`
  (尖端伸入液滴内部);
- **半径剖面** = 融合倒角:rise 从尖端 0 → 表面交点处升至 1(smoothstep 凹形舒展,
  露出即全径,切线连续;BlobTree fillet 的网格等价);
- **内部段隐藏**:新增逐顶点属性 `aFade`(CPU 每帧算:尖端 0 → 表面交点前 0.25 处
  开始升 → 表面交点=1),桥 alpha × vFade → 液滴内部段透明,lux 无深度写入也无缝;
  灰模路径有深度写入,几何天然被液滴遮挡,零改动;
- 端径/颈径/拉伸变细/高亮加粗全部沿用。

### 3-3 任务③ 夜晚发光小球 + 暖黄桥缘(两 shader 的 uNightDots 分支)

- 液滴:`uNightDots>0.5` 早退分支 → 暖黄(1.0,0.70,0.30)×1.9 HDR 自发光 +
  边缘 rim + 白热 GGX 核 → UnrealBloom(night threshold 0.55)自动出光晕;
- 液桥:同分支 → 暖黄体 0.42 + rim(pow(1−nov, 2.2))×1.75 边界亮线
  (委托方「暖黄色边界线」= 侧视轮廓亮线),alpha mix(0.38, 0.92, rim);
- 引用调研第 3 行:阈值式 bloom,HDR>threshold 即自成光源。

### 3-4 任务④ 液滴透镜放大扭曲光纹(LUX_DROPLET_VERT/FRAG)

- 顶点新增 varying:`vCenter`(滴心世界 xz;instanceMatrix 平移分量)、
  `vR`(实例半径;instanceMatrix 基向量长)、`vLocalY`(单位几何高度);
- 片元:`bpos = vCenter.xz + rd.xz·(LENS_PATH/max(−rd.y, 0.3))`,
  `LENS_PATH = vR × CAUSTIC_LENS_MAG(3.2)`——以滴心为基准的等效光程
  (GPU Gems 2 光程缩放;原型 LENS_DEPTH 同思想;液滴口径 ~5cm 对焦散网胞
  ~29cm,等效光程必须数倍于 r 才能在滴内铺开可读的网纹窗口);
- 透过液滴的 shadeBottom 采样本身含焦散网 → 光纹被球面法线扭曲 + 中心放大;
  ×1.25 提亮(透镜聚光)。

### 3-5 任务⑤ 傍晚水底米白(presets.ts)

- `DUSK.bottomAlbedo [0.34,0.4,0.52] → [0.9,0.85,0.72]`(米白偏米;r>g>b);
  按 ACES 标定:傍晚光照(弱低角暖光+暗环境)下屏显 ≈ sRGB(0.91,0.86,0.82)。
  焦散网加光走 uSunColor 琥珀色,米白底上呈金色细丝(傍晚既有观感加强)。

### 7-2 悬浮态视觉异常抖动修复

委托方反馈:鼠标移到液滴上、液滴悬浮时异常抖动。诊断(2026-09-10 实机数值探针,
物理步频采样):
- 悬停升力使液滴浮出(悬浮态)时,「悬停液滴持续强化波纹」泵(watersim/engine.ts
  §1.6)在滴下激起 **±9mm@~9.8Hz** 的原始场高纹波;
- 物理层第四批已用 zFollow(τ=0.1s)平滑 `d.z`,但**渲染层 `lensBottomY` 仍直接
  采样原始 `totalHeight`** → 液滴网格逐帧跟随高频纹波 → 视觉抖动(实测原始场高
  单步最大变化 1.3mm,平滑值 0.06mm,高频成分差 ~20 倍;第三批/第四批修的是
  控制器滞后与物理 z,渲染路径漏网)。
修复:浮态渲染底面 = `d.z − r + amb`(≡ 平滑水面 − 浸深;升力浮出、波浪 riding、
液桥锚定同源关系全部继承;环境波涛慢变另行叠加,聚焦悬浮分支不加 amb 保稳定)。
实测修复后渲染底面单步最大变化 0.06mm(修复前同口径 1.3mm)。
