## 0. 项目速览与铁律（自 09-10 / 09-11 并入）

- 产品：水滴关系网小说阅读器 · 三维水体物理 + 光影渲染（`web/`，three.js r185 + Vite）。
- **生产侧铁律（继续有效）**：
  1. **物理引擎是唯一时间源**——效果由 viewer 主循环喂 dt，不引第二时钟；
  2. **效果驱动 three-free、纯逻辑、可单测**（`src/fxspike/fxdriver.ts` 等）；
  3. **uniforms 被 5 个材质共享** → 逐桥 / 逐滴状态只能走**逐顶点 / 逐实例属性**；
  4. **`three` 只许 `grayview/viewer.ts` import**；
  5. 液滴不透明且写深度 → **一切出场 / 退场禁用 alpha 淡入**（只走 dissolve / scale / lift）；
  6. **加性项与时间调制项都要钳**（夜闪三次整改的根因）；基线像素等价纪律：
     未注入 `FxSource` 时渲染路径与原生产**逐字节等价**。
- 生产"零改动"红线已于 2026-09-12 由委托方解除（成果回灌，见 §14）。

## 4. 四项产出现状

### 4.1 粗细可变（清单 A-2 的前置验证）

- 委托方明确：**最佳效果里粗细范围变化不能过大**，只需验证「可变」。
- 实现：`FxDriver.thick` 可设值（默认基准 1.0），`bridgeThick(seed)` 返回它；
  viewer 侧 `BRIDGE_THICK = {min:0.55, max:1.85}` 钳制不变，仍只有一个入口。
- 证据（`截图-2026-09-11-B组增补/1-粗细-*.png`）：同一机位 fx=0（**关**）下
  0.70 / 1.00 / 1.85 / 3.00 四帧——3.00 被钳回与 1.85 一致（钳制有效）；
  fx=0 生效证明粗细不属于任何状态。说明框叠读数 `[thick] 粗细系数=…(钳 0.55~1.85)`。
- **数据映射仍未接**（无数据来源）；接入时按委托方口径设计为**窄幅**映射。

### 4.2 文字叠层（清单 A-1 / A-3 的文字部分）

- 方案 = **HTML 叠层**（委托方授权实施方选最佳方式）：无底牌光晕字，挂液滴
  正下方（中心 + 1.35r + 8px，不压滴体）；日间 = 墨青字 + 米白光晕，深夜 =
  月光淡银 + 暗晕（`#fx-labels.night`，随时段按钮实时切换）。
- 规则落地：在场滴 → 名字（`.name`）；已退场 → 关系说明（`.gone`，示例
  「已故 · 挚友」）；未出场 → 「未知关系」（`.unknown`）且**滴中无名字**；
  灰滴标签随浮现渐显（`labelAlpha`：浮起 70% 前不显）。
- ⚠ 文案为**示例占位**（中心·主角/人物甲/人物乙），真实数据接入时替换
  （`main.ts` 的 `LABEL_TEXTS`）。
- 已知边界：**不做遮挡判断**（标签恒在最上层；液滴网络俯视浅景互相遮挡罕见，
  真要做需读深度缓冲，验证页不值当）。规格 §7.2 的「节点密时隐藏名字」密度
  规则未验证（验证页固定 6 滴）。
- v1（深色底牌 pill 式）被委托方 2026-09-12 审核退回，其证据帧保留在
  `截图-2026-09-11-B组增补/2-文字-*.png` 仅供对照，**样式已废弃**。

### 4.3 灰滴浮现 =「从无到有」（动效 §2.3）

- 委托方退回原因：「很明显能看见是从小液滴扩大」。现行实现：
  - `scale` 恒 1（**任何阶段都没有尺寸生长**）；
  - 浮现 = 整颗从水底升上来（`lift: -ABSENT_DEPTH*(1-rise)`，不变）；
  - 「从无」由**反向 dissolve** 承担：`dissolve = 1 - smooth01(span01(rise,0,0.45))`
    —— 复用死亡溶解的 hashed alpha discard 通道（1=全丢 → 0=完整），丢弃
    既不写色也不写深度，任意进度深度正确、不留洞；不新增通道、不动 depthWrite。
- 标签渐显时点不变（rise 0.7 → 1.0，文字仍晚于液滴出现）。

### 4.4 深夜白色频闪（缺陷修复）

- 委托方报修：「深夜模式下整个界面间隔数秒出现白色频闪」。
- 定位（活页面连拍对比 + 冻结帧 `?pt=` 扫相位）：元凶是**生物荧光海岸**
  `nightCoast`——岸线辉光呼吸原幅度 0.55±0.45（局部近熄→全亮，亮段沿线游走）
  与颗粒 `tw`/`life` 的快端周期（≈6s）叠加 → 整条岸线周期性爆白。即生产
  第三次整改（「约6秒一次白闪，仅俯视近距可见」）只压了**颗粒峰值**、
  没动**调制深度**留下的尾巴。
- 修复（四处，全在 `nightCoast`，水底/水面/液滴三视图共用）：
  | 项 | 修前 | 修后 |
  | --- | --- | --- |
  | breathe 幅度 | 0.55±0.45 | 0.55±0.30 |
  | 岸线核心乘数 | core*(0.45+0.55*breathe)，峰≈1.0 | min(同式, **0.72**) |
  | 颗粒 pBrt | ×1.15 | ×1.0 |
  | 颗粒 tw | 0.6±0.4 | 0.72±0.28 |
  | 大颗粒增益 | 0.85+0.9*big | 0.85+0.5*big |
- 量化验证：活页面相邻帧亮度摆 **±10~15% → ±3%**（只剩慢呼吸漂移）；冻结态
  跨相位摆幅 **±7% → ±0.5%**；修前后同视口基准帧均值 125.63 vs 126.03
  （−0.3%，夜色基调未误伤）；岸线形态（线束/蜿蜒/推进/闪砾）保留。
- ⚠ 修前/修后对照帧已存档：`截图-2026-09-12-文案灰滴夜闪/1-夜闪-整改前-*.png`

## 6. 技术教训（本轮实测踩出来的）

### 取帧 / 冻结路径

1. **shot 模式下 `hooks.tick` 冻结后不再执行**（它在 viewer tick 的
   `if (!paused)` 里，而预滚末尾会点「暂停」）。任何「每帧摆放」的一次性 DOM
   叠层（文字标签）必须在**预滚结束、暂停之前按最终状态补摆一次**——初版只在
   tick 开头摆过（t=0、相机矩阵未就绪、灰滴 alpha=0），画面里标签全消失。
2. **冻结帧不能证周期现象**：`?pt=` 把 simTime 钉到任意相位后扫帧，才能量化
   「摆幅」。摆幅数字要**同视口**比：960×540 与 1280×720 的整帧均值差 ~6%
   （深色 HUD 面板占像素比不同），跨视口对比会得出假阳性。
3. 活页面对 WebGL 页连拍截图会超时（IAB 30s 上限）；备选是页面内 rAF 探针
   `gl.readPixels`（渲染后同帧读才有效），但全帧读取会把 120fps 拖到 ~1fps，
   只能改采水平条带。**最省的还是截图连拍 + pngstat 亮度统计**（/tmp/pngstat.js，
   Node 内置 zlib 手写 PNG 解码，本机无 PIL/ImageMagick/ffmpeg）。
4. `screenOf` 读的是**引擎坐标**，不含效果偏移；灰滴 lift 是 instanceMatrix 的
   Y 平移 → 探针加 `lift` 参数对齐**渲染位**，别在叠层侧自己补算。

### 渲染 / 夜色

5. 「压峰」类修复要检查**调制深度本身**：生产三次夜闪整改压了颗粒 HDR 峰值，
   但岸线呼吸的全幅摆动（近熄→全亮）还在，委托方照样看到频闪。结论：
   加性项要钳（既有纪律），**时间调制项的摆幅也要钳**。
6. 夜间定格基线的水色是**薰衣草紫**（并非深蓝）——深蓝只出现在某些活页相位。
   判断「夜色对不对」要先固定相位再比，且修前后必须**同视口同参数**。

### DOM 叠层

7. 叠层靠 **DOM 顺序**分层：labels 根节点在 `mountLuxViewer` **之后**插入
   `#app`（排在 canvas 之后、HUD 兄弟之前），不用 z-index；`pointer-events:none`
   保交互。
8. 标签挂液滴**正下方**而不是正中：深夜滴是大亮球，字叠上去读不出；下方水色
   背景上光晕字最可读、最融入（v1 退回的主因之一就是字压在滴上+底牌感）。

### 10.5 本段教训（实测踩出来的）

1. **巨滴长成窗压错阶段**：初版在汇聚段就长巨滴，把滑入中的旧滴吞了，
   「汇聚」读不出 → 长成窗移到过渡段前半，悬停段全程保持 4.2×。单测守护。
2. **增辉也要钳**：bloom +1.1 整帧泛白（washed-out）→ +0.45 + 蓄力 flash 减半。
   夜闪整改的结论（时间调制项摆幅要钳）在**空间增辉**上同样成立。
3. **粒子要个体错峰**：48 颗同步同距 = 规整圆环，不是炸裂。方位/半径/时长
   三重抖动后才读成 splash。
4. **交换删除 × 角色表**：`removeDroplet(0)` 会把末位新滴搬到索引 0 ——
   角色表必须按同规则重排（`[last, ...slice(1,-1)]`），否则错峰次序错乱。
5. **`__gray.sync` 顺序**：取帧路径先 `syncDroplets`（写偏移缓存）再
   `syncBridges`（读缓存），整场压一帧时桥才不脱节。
6. HUD 面板（backdrop-filter 毛玻璃）在缩略图上像「灰色悬浮矩形块」——
   对比旧帧确认非渲染缺陷，别误诊。

2. **池扩容要检查消费端**：光点池 96 让爆散火花悄悄变 96（违反「之后不变」），
   靠步骤 6 证据帧对照抓到 → `i ≥ SPARK_COUNT` 恒 null + 单测守护。
3. **静帧要能读出「螺旋」**：抵达窗太窄 → 同一时刻各点半径几乎相同 → 读成「一圈
   珠子」。放宽抵达窗 + 旋臂宽度 + 盘面散布，静帧里才连成螺线。
4. **`flash` 是死通道**（viewer 只声明、无处消费）：方案里的「溃散/凝聚闪点」按事实
   去掉;要真接线需动液滴 shader（影响所有模式），另开。

### 12.1 改动要点

| 项 | 整改前 | 整改后 |
| --- | --- | --- |
| 材质 | 珠光透镜（菲涅尔 + 天光 + 太阳高光）= **小水珠** | **纯光点**：细亮核 + 宽淡晕（`fall = 0.55(1−rl)^5 + 0.45(1−rl)^1.6`）；**rgb 与 alpha 同廓** |
| 混合 | NormalBlending | **预乘 alpha**（One / OneMinusSrcAlpha）—— 柔边不压暗背景 |
| 夜色 | 吃环境光，夜里发暗 | **暖橙发光**（= `LUX_DROPLET_FRAG` 夜色分支同色 `vec3(1.0,0.70,0.30)`），越 bloom 阈值 0.7 出晕 |
| 尺寸/数量 | 0.009–0.013（≈滴径）；池 96 | **0.004–0.007（≈滴径 1/3）**；池 **160**；爆散段粒径 0.009→0.005（**数量仍 48**） |
| 运动 | 从滴盘面直接起旋 | **炸裂外冲**（径向 easeOutCubic，幅度≈滴径、个体 0.6–1.4×）→ 漩涡吸入；**全程离水悬浮**（8–16mm 基高 + 中段抬升）+ **横向游移**；出现改 0.035s 快闪 |
| 滴体 | 溶解 0.20s | 炸开 **0.14s**（更「炸」），旧桥卷没随之前移到 0.36s |

### 12.2 实测教训（新增）

1. **柔边发光点必须「同廓」**：alpha 廓线宽于颜色廓线时，边缘会把背景**压暗成暗环**
   → 整颗读作「带暗边的小珠」（初版证据帧实测）。预乘 alpha 下让 `rgb = 常量亮色 × 同一条
   廓线`，任何半径**只亮不暗**才是「光」。
2. **「同物种」共享池 = 换材质要同时看两段**：材质是两段共用的（这是委托方要的「一样」），
   所以外观类改动天然同时作用于汇聚段与爆散段；**数量/时序/曲线不在材质里**，
   由 driver 钳制（`i ≥ SPARK_COUNT` 恒 null）→ 满足「一起换外观、不动运动」。
3. 尺寸减半要用**数量补偿**（96→160）才不会读稀；浮尘感靠**高度（离水）+ 微游移**,
   不是靠轨迹噪声（后者会毁掉漩涡读感）。

### 13.1 两条改动

| 项 | 前 | 后 |
| --- | --- | --- |
| 炸裂方向 | 沿「域心→源滴」径向**外推**（被推离画面中心） | **局部位移 + 绕滴心均匀方向** → 光点围着原滴散开（`POINT_BURST_R 0.032`，个体 0.6–1.4×） |
| 凝滞后 | 炸开量一路衰减、漩涡立刻接管 | 三段进程 `[0.2, 0.46]` 为**凝滞窗**（位移保持、漩涡未启动，≈0.2s，仅 0.8mm 级微颤） |
| 正午水面 | 均值 192.9/255（近惨白，结构读不出） | **179.9（−6.8%）**：曝光 1.0→0.5（主刀）+ 太阳 3.3→2.75 + 焦散 1.35→1.0 + 池底反照率深一档 + 边缘提亮 0.16→0.06；**其他时段零回归**（傍晚基线 181.44 逐值一致） |

### 13.2 实测教训（新增）

1. **先定位「你看到的是哪一层」**：正午的「水面」其实主要是**池底平面**（水面 alpha 置 0
   画面不变 ⇒ 水面贡献≈0）。判层靠「强制着色器输出显色」（红/深灰）+ alpha 置零对照，
   比读代码猜快得多。
2. **过曝场景的杠杆是曝光、不是材质**：逐项消融显示池底反照率/水色/天空/背景对整帧均值
   **≤1%**，太阳 −13%、曝光 −5% —— 因为 HDR 整体压在 ACES 肩部。与社区口径
   「先动 tonemapping/exposure、后动 albedo」一致；本轮据此做**组合标定**。
3. **过曝下单项调参会被误判为「无效」**：所有候选都只有 ±1% 时，别继续加参数 ——
   先判「是否整体过曝」，再一次性拉回中间调。
4. 单测判据要量**该量的东西**：凝滞应当直接量「一段连续静止窗」，用「与源滴距离的峰值」
   当起点会落到抵达端（源滴在环上，终点离它 0.12），判据全错。
