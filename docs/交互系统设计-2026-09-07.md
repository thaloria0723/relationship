# 交互系统设计 · 模块②(灰模阶段)

日期:2026-09-07。依据:`docs/视觉系统模块规格-2026-09-05.md` §1/§6(模块②铁律)+ 委托方四特性指令。实施会话自行设计并动工(委托方授权免中途验收)。

## 0. 模块边界(铁律)

- 模块②=「输入 → 意图」:**three-free、无颜色/GLSL、无 DOM 依赖的核心**(`web/src/interaction/`),vitest 直测(mock 输入)。
- 命中检测 = **解析圆测试**(屏幕空间圆,禁止 Raycaster,§6)。
- **转场期冻结输入**(§6):焦点模式进出过渡期(~0.6s)丢弃一切新意图。
- 意图注入物理:引擎新增「意图 API」(悬停/拖拽/焦点);意图是抽象数据,不带任何视觉属性。压暗/高亮/相机动画全部在 viewer(模块③位)执行。

## 1. 架构

```
DOM 事件(viewer 适配层)
  → 指针采样 { 屏幕x,y | 水面世界x,y } + 场景快照 { 各滴屏幕圆 (px,py,pr) }
  → InteractionController.update()(纯逻辑,可测)
  → Intent[] { hoverWater / hoverDroplet / dragStart / dragMove / dragEnd
              / focusEnter / focusExit }
  → WaterEngine 意图 API(物理效果)
  → viewer 表现(相机推拉 / 灰度压暗高亮)
```

## 2. 意图 → 物理 → 表现 映射(四特性)

| # | 意图 | 引擎物理 | viewer 表现 |
|---|---|---|---|
| 1 | `hoverWater(x,y)`(指针在水面上) | 每 0.12s 注入微体积源(σ=15mm,峰深 ~0.3mm)→ 微弱涟漪 | 无额外 |
| 2 | `hoverDroplet(i)` | 该滴升力系数 lift→1(0.3s 平滑):有效平衡浸深 d*×(1−0.55·lift) → 浮出水面;浸深变化经既有 ΔV 耦合自动辐射较强波纹 | 指针光标提示 |
| 3 | `dragStart/Move/End(i, x,y)` | 拖拽中:速度导向指针(强阻尼);锚点=抓取时位置;释放:欠阻尼弹簧回锚(k=6s⁻²,c=2.2s⁻¹,ζ≈0.45,缓慢弹回 ~2.6s);桥张力随动 → 桥变形、邻滴连锁(网络动力学自然涌现) | 拖拽光标 |
| 4 | `focusEnter(i)` / `focusExit()` | 分组 G={i}∪直连桥邻居;G 内 levitate(悬浮:z 目标=水面+(r+0.08m),临界阻尼逼近;水平坡度力关闭);**跨界桥临时切断**(cut=1:张力关/不渲染/流量清零),退出恢复 | 相机推至 G 质心正上方(0.9m 高,0.6s 缓动);过渡期冻结输入;非成员液滴/桥与水面压暗(灰度降低),G 内液滴/桥提亮(灰度提高,无彩色) |

退出:`focusExit` 的触发 = 焦点模式下双击空白水面或按 Esc。

## 3. 命中检测(解析圆)

- viewer 每帧投影各滴:屏幕圆心 (px,py),半径 `pr = r·f/dist`,f = 0.5·viewportH/tan(fov/2)。
- 命中 = 指针在圆内(容差 max(pr,14px));多圆包含时取 `dist/pr` 最小者;平局取索引小(确定性)。
- 水面定位 = 指针射线与 y=0 平面解析求交(viewer 做,three 相机数据,非 Raycaster 场景遍历)。
