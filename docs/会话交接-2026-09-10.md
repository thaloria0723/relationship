## 4. 第十一批改动摘要(2026-09-10:液滴可视性 + 液桥融合 + 夜光 + 米白底)

### 4-1 委托方五任务与最终状态(全部达成,实机截图核验)

1. **液滴可视程度低(尤其清晨/正午)** → 根因 = 旧液滴材质与液面同套透明水公式
   (alpha 0.15~0.7 + uTint 洗色)。重写为 `实例.png` 珍珠乳白小球:奶白壳
   (uTint 时段化)× 0.45 + 透镜折射水底(蓝核)× 0.55 + GGX/柔光高光 + 底缘
   接触亮环,`alpha = mix(0.66, 0.94, F)`;正午 surfaceTintAmt 0.55→0.68(委托方
   许可改水面色)增强对比。清晨/正午实机:液滴从隐形/暗点变为清晰珍珠网络。
2. **液桥伸入液滴 + 曲面化融合** → 尖端从「恰在表面 0.866r」改为伸入内部 0.5r;
   半径 smoothstep 凹形舒展恰在表面交点(0.866r)处升满(切线连续融合倒角,
   BlobTree fillet 思想的网格等价);新增逐顶点 `aFade`(尖端 0→表面交点 1)
   令滴内段透明隐藏(lux 无深度写入也无缝;灰模深度写入天然遮挡)。
3. **深夜发光小球 + 暖黄桥缘** → 两 shader 的 `uNightDots>0.5` 早退分支:液滴 =
   暖黄 (1.0,0.70,0.30)×1.9 HDR 自发光 + rim + 白热核(bloom threshold 0.55
   自动出光晕);液桥 = 暖黄体 + rim(pow(1−nov,2.2)×1.75)边界亮线。实机:暖黄
   发光网络悬于荧光海岸之上,效果显著。
4. **液滴折射扭曲放大水底光纹** → 顶点传 vCenter(滴心 xz)/vR(实例半径),
   片元以滴心为基准、等效光程 `vR×CAUSTIC_LENS_MAG(3.2)` 采样 shadeBottom
   (GPU Gems 2 ch.19 光程缩放;原型 LENS_DEPTH 同思想)→ 滴内可见放大扭曲的
   焦散网,×1.35 聚光提亮。
5. **傍晚水底米白** → `DUSK.bottomAlbedo [0.34,0.4,0.52]→[0.9,0.85,0.72]`
   (r>g>b 米色倾向;ACES 标定屏显 ≈ sRGB(0.91,0.86,0.82))。实机:米白底上
   琥珀金焦散丝。

- 相似度判定(对照 `实例.png` 五要素):奶白体 ✓ / 蓝核 ✓(偏弱可辨)/ 亮部
  高光 ✓ / 接触亮环 ✓ / 投影 ✓——**达标,未触发回退步骤3**。
- 物理与交互**零改动**(铁律遵守);焦散核/荧光海岸/波涛谱字节级未动。

### 4-1s 同日整改(委托方复核反馈,详见设计文档 §7/§8)

1. **任务②整改「两端适当放大 + 深入液滴 + 隐藏内部 + 接触面圆滑过渡」**:
   端径 0.16→0.30r(漏斗形)、尖端深入 0.5→0.45r、新增 BLEND_EXTEND=1.35
   (倒角恰越过表面完成,圆滑过渡);桥形常量全部模块级导出 + 有界守护。
2. **悬浮态视觉异常抖动修复**:根因 = 悬停涟漪泵在滴下激起 ±9mm@~10Hz 纹波,
   渲染层 `lensBottomY` 直用原始 `totalHeight` 逐帧跟随(物理层 zFollow 已平滑,
   渲染层漏网)。修复 = 浮态渲染底面改用物理平滑值 `d.z − r + amb`,实测抖动
   降 ~20 倍(1.3mm→0.06mm/步)。`@types/node` 加入 devDependencies(源码级
   守护测试需要),tsconfig 加 `"types": ["node"]`。
3. **二次整改「滴内液桥仍可见」**:aFade 渐变横跨滴内段 + 透明队列无深度遮挡,
   桥整段叠画在球面。修复 = `dropletMat.depthWrite = true`(珍珠近不透明,
   滴内/滴后桥段与雾被深度测试真实剔除,任意视角正确)+ `BRIDGE_FADE_START
   0.25→0.8`(aFade 退化为出场边缘软化)。同机位前后对比见截图目录
   `改前二次-滴内液桥可见-取证 / 改后二次-同机位-滴内桥已遮挡 /
   改后二次-近景-桥止于球轮廓`。
4. **三次整改「夜晚不定时白色闪光 + 夜滴/桥过亮」**(设计文档 §9/§10):
   - 白闪根因(三层,均已钳制):①水面 glitter 项 GGX(uRough 0.09)D 峰值数值
     无界,弹坑缘/波峰扫过月亮方向时 HDR 10+ 白爆 → `min(·, GLINT_CLAMP 0.45)`;
     ②**夜晚液滴/桥分支的 GGX(0.18/0.22)未钳**——网络内桥姿态相近,晃动时
     法线同步扫过月亮半向量 → 整网同步白闪(页内 readPixels 触发探针抓帧确认,
     `改前三次-深夜-全网桥同步白闪捕获帧.png`)→ 液滴 `min(·×1.2, 0.25)`、
     液桥 `min(·×0.9, 0.2)`;另反射圆盘项 `min(pow600×4, 1.2)`;
     ③**海岸大颗粒**(委托方实测:约 6s 一次、仅俯视近距可见、远距几乎不见):
     颗粒毫米级 + tw/life 周期快端 ≈6.3s + 线上峰值 HDR≈6.8 近白 → 白闪;
     修复 = `pBrt ×1.15`、大颗粒加成 `(0.85+0.9·big)`(峰值 ≈2.0,闪烁观感保留);
   - 夜滴/桥亮度下调:液滴 1.15/0.55、液桥 0.28/0.85、夜环带 0.32
     (仍 > night bloom 阈值 0.55,柔光晕保留);
   - 复验:触发探针(整帧亮度 >基线12% 即抓帧)深夜稳态 34 sim 秒/~2500 帧
     零触发(修①②);修③后全片 maxL ≤730(前满饱和 755);剩余稀发整帧
     +9~11% 事件(约 2s)为海岸呼吸/推进波到岸设计内行为,如仍觉刺眼再调
     breathe 幅度(待确认)。诊断工具留档:页内 readPixels 逐帧亮度探针 +
     在线触发抓帧(设计文档 §9-3/§10,可复用于后续闪烁类问题)。

## 5. 关键裁决与教训(新会话勿翻案/勿重蹈)

1. **液滴材质路线已裁决**:实例.png 珍珠乳白(奶白壳+蓝核+高光+接触环,高不透明
   alpha 0.66-0.94)取代旧「与液面同族透明水」路线;勿在无新委托下改回透明公式。
2. **液桥融合 = 几何伸入 + 倒角 rise + aFade 透明隐藏**三件套;lux 透明队列无深度
   写入,隐藏滴内段必须靠 aFade(深度遮挡不存在);灰模靠深度写入天然遮挡,勿给
   灰模加 aFade 处理。
3. **夜间发光走阈值式 bloom + HDR**(材质 HDR > night bloom threshold 0.55 即
   自成光源),勿引入选择性 bloom/光源体等重方案。
4. **透镜放大 = 滴心基准 + 等效光程 vR×3.2**;勿用池底直视光程(uPoolDepth)——
   液滴口径 ~5cm 对网胞 ~29cm,直视光程采样窗过小,滴内无纹可读。
5. **物理平滑与渲染必须同源**:第四批给物理层加了 zFollow 平滑 d.z,但渲染层
   `lensBottomY` 仍采原始场高,悬停涟漪泵(±9mm@~10Hz)直接抖给用户——「改了
   物理 ≠ 修了视觉」。现浮态渲染底面 = `d.z − r + amb`,勿改回原始场高。
6. 沿用教训:GLSL 变量名避开 `patch`(保留字);pow 底数 abs/clamp 先行;
   原型 index-wave.html 是合法参照但变量名须逐个查保留字;材质编译失败=整片消失
   (`__gray.renderer.info.programs[].diagnostics` 诊断)。
7. **沿用的既有裁决全部有效**(09-09 交接 §5/§8/§9 + 第十批 §5:焦散 v4 勿重试
   v2/v3、桥 30% 透明、夜光点生物荧光蓝、液桥锚定同源、域扭曲折叠约束等)。
