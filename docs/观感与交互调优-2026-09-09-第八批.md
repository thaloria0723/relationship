## 3. 夜晚生物荧光浪缘(nightBiolum,参考图2 逐条落实)

- **结构**:脊状 fbm(ridged noise,`1−|2n−1|`)的中值等值线——随机自然形态的
  连续弯曲边界网络,非规则圆环、非人工描线;**不取仿真波场 lap**(结构独立于涟漪,
  按需求「不是规则圆形波纹」声明)。三个 octave(2.4/4.9/9.3 /m)→ 域内数条主线 + 细部弯曲。
- **动态**:①整体沿 +x 横向平移(0.055 m/s,模拟海浪,波形随平移保持);
  ②低频慢变剪切型域扭曲(幅度 0.045m,|∂W|≈0.54<1)→ 边界缓慢局部收缩/扩张/弯曲,
  整体结构稳定。
- **亮度**:蓝白窄核心(`exp(−d²·55)`,d=1−脊值)×(0.55+0.45·呼吸) + 外围蓝色散射辉光
  (`exp(−d·5.5)·0.42`)——高斯/指数双重快速距离衰减;呼吸 `0.72+0.28·sin(0.4t+14e)`
  以脊值自身为相位 → 各段**非同步**慢变化。全部亮度集中于边界局部,环境光近黑(局部性)。
- **颗粒**(uDotCell=0.026m 格点哈希):密度 `0.12+0.88·exp(−d·4.5)` —— 边界附近最密、
  向外围渐降;极低速随机漂浮(双频慢摆 ±0.24 格,各颗粒相位随机,无统一方向);
  随机生命周期(周期 6-20s,25% 淡入/30% 淡出)+ 亮度缓变(与生命周期不同相);
  尺寸高幂偏置 `pow(hash,7)` —— 多数 ~1mm 极细小、少量 ~4mm 且亮度 ×(0.35+1.3·big)
  → 仅少量颗粒越过 bloom 阈值泛辉光(「仅少量颗粒明显更亮」)。
- **接入路径**:`shadeBottom`(水面/液滴折射视图)与水底 mesh 片元共用同一 nightBiolum
  → 荧光边界透过透明水面带折射扭曲呈现,垂直俯视时水底直视占 ~83% 亮度主导。

## 4. 清晨粉紫 + 上方雾气层(参考图1)

- **粉紫色调**:水面 `surfaceTint [0.82,0.65,0.86]`×0.4;地平线 [0.92,0.72,0.78](粉)/
  天顶 [0.45,0.42,0.72](紫蓝)→ Fresnel 反射带粉;环境天空 [0.56,0.52,0.7];
  雾色 [0.85,0.75,0.87](粉紫白);背景 [0.6,0.57,0.72];晨光保持暖金 [1.0,0.8,0.62]
  (参考图1顶部暖阳光晕)。
- **雾气层**(新 mesh,LUX_MIST_VERT/FRAG):水平薄片 y=0.055(液滴上方:滴顶
  = 波高+rMax ≈0.038),2.2×域,域边 0.34→0.56m 淡出;程序化团涌 = 低频大团
  (域扭曲防直纹)+ 高频絮丝(0.68/0.32 加权),双频慢速漂移;掠射淡出
  (`dot(+y,视线)²`)+ 层下 facing=0 不可见 → 防平板剪影;强度 = 预设 `mistLayer`
  (唯清晨 1.0,正午/傍晚/深夜 0),随 presetLerpTau 平滑渐变;alpha 上限 0.5 团簇化
  (团与团之间留空隙)。renderOrder 11 = 透明队列最后(相机在层上方时它是最高透明物,
  最后画即正确 back-to-front)。与既有 `applyMist` 高度雾(density 0.16)叠加 →
  远近双层雾观感。

## 5. 关键裁决与教训

1. **夜光点金色裁决已被推翻**:「夜光点金色(r>g>b 测试锁定)」(交接 §5-6)自本批起
   替换为**生物荧光蓝(b>g>r)**;presets.test.ts 断言同步更新。uNightDots/uNightDotColor/
   uDotCell 三个 uniform 名保留(语义 = 夜晚荧光层开关/基色/颗粒格点),避免无谓重命名。
2. **水面/液滴淡蓝写死 → 时段化是本轮结构性裁决**:深夜靠 `surfaceTint` 深蓝替代淡蓝,
   才能达成「整个场景黑+深蓝」;正午/傍晚以 0.55/0.55(液滴 0.55×0.64≈0.35)保持旧观感。
3. **-0 陷阱(上轮遗留缺陷,本批首跑暴露)**:`ambientWaveHeight` 在 h<0 且 ampScale=0
   时返回 -0,`toBe(0)`(Object.is)判定失败——上轮因进程饱和未能运行测试而漏网。
   已改 `toBeCloseTo(0,15)`(容忍零符号)。教训:**新增测试必须实际运行过才能交接**。
4. **雾层是视觉层**:不进物理、不吃 grade(与 applyMist 同在 grade 后混合);
   强度唯一入口 = `LightingPreset.mistLayer`。
