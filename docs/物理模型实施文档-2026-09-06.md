## 0. 背景与定位(实施会话必读)

本项目的视觉层正在按图形渲染系统规格拆分为 物理模型 / 交互系统 / 光影渲染 三模块(见 `docs/视觉系统模块规格-2026-09-05.md`)。本阶段只做**物理模型**,且采用**全新流程**:不是在已有视觉代码上调整,而是从物理定义出发重新构建。

- 仓库根目录 `index-wave.html` 是已封版的视觉基线(PixiJS,**禁止改动**,仅供最终对照)。
- `web/src/physics/` 内是此前对封版视觉公式的 TS 移植(analytic 观感场,非真实物理)。**保留不动**,仅作参考;新引擎一律写在 `web/src/watersim/`,与旧文件零耦合。
- 工程底座已就绪:`web/`(Vite 8.2.2 + TS 7.0.2 strict + three 0.185.1 + vitest 5.0.0,精确钉版)。运行 `cd web && npm test` / `npm run dev`。
- 工作纪律:**TDD(先测后码)**;`import three` 只允许出现在查看器文件;引擎本体零渲染依赖。

## 1. 目标与验收形式

构建一个**真实水体物理仿真引擎**(CPU,固定步长,确定性),并在网页上以**灰模**呈现:

> **最终验收 = 网页上的灰模:没有任何光影、没有任何颜色渲染,仅展示物理模型本身。**
> 水面是可位移的灰色网格面,液滴是灰色球/扁球,观者能直接看到:波的传播、落滴激起的涟漪、液滴下方的水面凹陷、液滴漂浮/漂移/碰撞/压扁/聚合。

非目标(本阶段禁止):光影/反射/折射/颜色、交互系统(鼠标对水的扰动不做,调试按钮除外)、粒子飞溅细节、液滴破碎、真 NS 求解器。

## 2. 物理定义(需求词表 → 机制映射)

### 2.1 水面(surface,连续场)

| 词             | 机制                                                                                   |
| -------------- | -------------------------------------------------------------------------------------- |
| **Wave**       | 高度场的行波:线性浅水方程的波动部分,速度 c,阻尼 λ,吸收边界                             |
| **Ripple**     | 局部波纹:液滴接触/运动/聚合向场注入冲量源,自然扩散                                     |
| **Flow**       | 水平流动:线性浅水的速度层(u,v),由高度梯度驱动 −g∇h,受摩擦衰减;可见性靠示踪点与液滴漂移 |
| **Distortion** | 局部畸变:漂浮液滴的**准静态凹陷核**(含贴边过渡),叠加在波动场上                         |

### 2.2 液滴(droplet,个体)

| 词                  | 机制                                                                                                                     |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Gravity**         | 空中自由落体(v=gt);入水后通过浮力差表达                                                                                  |
| **Buoyancy**        | 阿基米德:浸没体积球缺解 V(d)=πd²(R−d/3),平衡浸深由 ρ_w·V(d)=ρ_d·V_R 解出;漂浮深度可见                                    |
| **Surface tension** | ① 形状回复:压扁量 ε 的阻尼弹簧;② 毛细吸引:近距液滴互相靠拢(Cheerios 效应,量化放大以可见);③ 聚合驱动力:桥接范围内互相拉近 |
| **Collision**       | 球-球冲量碰撞(恢复系数 e)+ 位置修正去穿透                                                                                |
| **Deformation**     | 浮态压扁(ε_eq 随浮力载荷)+ 碰撞/聚合激发的阻尼振荡;渲染为 y 向缩放的球                                                   |
| **Merge**           | 桥接范围接触并保持 drainTime(排液延迟,防瞬聚)→ 聚合:V=V₁+V₂、动量守恒、形状踢振、涟漪脉冲                                |

### 2.3 耦合因果链(合同,每条箭头一个可测接口)

```
水滴接触水面 → 产生凹陷 → 水面产生波纹 → 波纹传播 → 影响附近水滴
   │              │             │             │            │
 接触检测      准静态凹陷核    冲量源注入     浅水传播      浮力采样+坡度力
 (d≤总高)   (kernel=−V_sub)  (Δ浸深/入水动量)  (波动+流动)  +毛细吸引
```

数值稳定的关键设计:**准静态/动态分离**——凹陷的静态部分用解析核直接叠加(不走反馈回路),只有**变化量**(入水冲量、浸深变化率、聚合)注入波动场。避免 液滴↔场 互相激励发散。

```
├── engine.ts           # WaterEngine 门面:固定步长管线(§4.4 顺序)、事件输出
├── demo.ts             # 演示场景脚本(§7 时间线,seed 确定性)
└── *.test.ts           # 与实现同目录,§8 测试计划
web/src/grayview/
└── viewer.ts           # 唯一 import three 的文件:灰模查看器(§6)+ HUD + 调试按钮
```

引擎管线每固定步(dt,双亚步/帧):

```
输入事件(演示脚本注滴/波源)
→ 液滴:空中积分(g)或浮态力求解(坡度力+阻力+毛细)
→ 液滴间:碰撞冲量+去穿透 → 毛细吸引 → 聚合判定与执行
→ 场:液滴动态源项(入水/Δ浸深/聚合脉冲)→ 浅水步进(波+流)
→ 场:重建准静态凹陷核列表
→ 事件输出(聚合/入水/HUD 统计)
```

## 4. 数值方法

### 4.1 水面场(线性化浅水)

- 网格 N×N Float32Array,状态:h(波高)、hu/hv(动量)或 (u,v)(流速层)。
- 波动:`h_tt = c²∇²h − 2λh_t`(Verlet/leapfrog);流动层:`u_t = −g_flow·h_x − μf·u + ν∇²u`,`∂h/∂t += −H∇·u`(质量守恒耦合,可参数关掉)。
- **g_flow = c²/H(派生,非原始 g)**:使浅水子系统波速 √(g_flow·H) ≡ c——单一波系、c 为唯一主参数。若用原始 g=9.81,√(gH)=0.70 m/s 产生第二波系且 CFL 直接爆(裁决见 §12-②)。原始 g 仅用于空中液滴段(M2 弹道下落)。
- flowOn=false 时浅水退化为纯 leapfrog 波动方程路径;两条路径实测波速均 = c(测试锁定)。
- **阻尼项隐式处理 + h 网格微扩散 0.01**:显式阻尼×半隐式回耦曾在 sponge 角落产生 +8%/步 的边界增长模(单次冲击短测抓不到,见 §12-③);隐式阻尼无条件耗散根治。扩散仅杀网格尺度模,对 ≥10 格波长可忽略。
- 边界:吸收(边缘 sponge 阻尼带,默认)或反射(参数)。吸收防"屏幕边反弹"假感。
- **CFL 断言**(启动时检查,超限直接 throw):`c·dt/dx ≤ cflSafety/√2`。

### 4.2 液滴垂直方向(免反馈设计)

- 空中:显式积分 z 与 vz(g)。
- 接触后:**不显式积分 z**。每帧解球缺平衡 d*(二次/三次求根),实际 d 向 d* 一阶弛豫(时间常数 τ_b ≈ 30ms)。垂直变化的可见后果全部走"冲量注入场"(入水 ∝ r²·v、Δ浸深 ∝ ḋ)。

### 4.3 液滴水平与形状

- 水平力:F = −ρ*w·V_sub·g·∇h(pos 双线性采样) − 6πμr·v_rel + F*毛细。
- 毛细吸引(近距,双方漂浮):`F = A·exp(−(s−(r₁+r₂))/ℓ)`,沿连线,仅吸引;A、ℓ 见参数表(量化放大,声明为风格化)。
- 形状:`ε'' = k_st(ε_eq−ε) − c_st·ε'`,`ε_eq = ε_max·(V_sub/V)`,碰撞/聚合时 ε 踢振。
- 聚合:表面间隙 < bridgeRange 持续 ≥ drainTime → 执行:r=(r₁³+r₂³)^(1/3),动量守恒,ε 踢,场脉冲,cooldown。

### 4.4 确定性与性能

- 固定步长累积器(渲染帧率无关),亚步上限(防螺旋死亡)。
- 全引擎无对象分配热路径(类型化数组原地更新);256² 场 + ≤32 滴 + 400 示踪点,目标 60fps 余量 2×。
- seed 驱动的演示脚本,同 seed 逐位可复现(测试断言)。

## 6. 灰模呈现规范(grayview/viewer.ts,唯一 import three)

- **零光照**:`WebGLRenderer` + `MeshBasicMaterial`(unlit),场景内不创建任何 Light。
- 水面:平面网格 256×256 顶点位移 h;实体面 **#9A9A9A**,叠加同几何**线框 #6E6E6E**(可开关,默认开——线框是几何显示不是光照);线框渲染用 64×64 降采样几何防糊。
- 液滴:灰 **#4A4A4A** 球体,scale=(1, 1−ε, 1);吃水线以下同样灰色(灰模不区分)。
- 示踪点:`THREE.Points`,灰 **#808080**,1.5px。
- 背景 **#C8C8C8**;相机 PerspectiveCamera 45°,OrbitControls(观察用,不属于交互模块)。
- HUD(DOM 文本,非 3D):fps、simTime、液滴数、累计聚合次数、波场能量;按钮:暂停/单步/重置/线框开关;滑杆仅 4 个:c、λ、capillaryA、mergeRipple。
- 启动即断言 CFL 与参数范围,违规 throw 并显示红字(灰模里唯一的"颜色"是错误提示文字)。

## 7. 演示场景时间线(验收脚本,seed 确定性)

| t(s)    | 事件                          | 应看到(=验收点)                                                                                   |
| ------- | ----------------------------- | ------------------------------------------------------------------------------------------------- |
| 0.0     | 静水场 + 3 颗漂浮滴(两滴近距) | 液滴下方持续凹陷(Distortion);浸深可见(Buoyancy)                                                   |
| 0.5     | 滴 A 自 0.15m 落于场中心      | 加速下落(Gravity);入水环纹扩散(Ripple)                                                            |
| 1.0–3.0 | 涟漪扫过漂浮滴                | 液滴随波起伏漂移(坡度力;耦合链末环)                                                               |
| 2.0     | 左缘波源启动                  | 等距波列横穿全场(Wave);示踪点被推动(Flow)                                                         |
| 4.5     | 近距两滴完成 drainTime        | 互相靠拢(Surface tension)→ 桥接 → **聚合**:大滴+形状振荡+新涟漪(Deformation/Merge),HUD 聚合计数+1 |
| 8.0     | 定时落滴持续                  | 周期性 Ripple;场面不发散(稳定性)                                                                  |
| 任意    | HUD 能量曲线                  | 静置时单调衰减;注入时阶跃                                                                         |
