## 0. 判定基准(拆条)

| # | 要求 | 现状差距 |

## 1. 调研与引用(步骤 3)

- **发光点 = 亮核 + 柔边 + 进 bloom**(社区标准做法):径向衰减用 `pow(1-r, k)` 控制
  「核的粗细」,亮核要越过后期 bloom 阈值才出光晕。
  <https://discourse.threejs.org/t/part-of-the-particle-glow/50562/4>、
  <https://stackoverflow.com/feeds/question/69252810>
  → **取用**:`core = pow(1-rl, 2.4)`、`edge = smoothstep(1, 0.65, rl)`;本工程 bloom 阈值
  **0.7**(`UnrealBloomPass(…, 0.7)`)、夜色 bloom 强度 0.38/傍晚 0.65 → 核亮度取
  日 1.5 / 夜 1.25 ✓(既有材质配色的量级)。
- **预乘 alpha(soft particle 暗边/暗环的根治)**:直通 alpha 混合下柔边会在半透明环上
  压出暗边;预乘后 `dst = src.rgb + dst.rgb·(1-a)`(=`Blend One, OneMinusSrcAlpha`),
  亮核可自然「加」出去、不污染背景。
  <https://devbytes.co.in/news/how-premultiplied-alpha-can-enhance-your-particle-effects>、
  <https://gamedev.net/forums/topic/661663-particle-alpha-blending/5185398/>
  → **取用**:光点材质改**预乘混合**(`CustomBlending: One / OneMinusSrcAlpha`),
  片元输出 `vec4(col·a, a)`。
- **炸裂的运动形态 = 径向初速外冲(减速)→ 吸引子接管**(爆炸-吸入两段):
  与本仓库**爆散段既有实现同源**(`sparkState`:easeOutCubic 外冲 → 悬停 → 被牵引),
  外部对应物见上轮引用的黑洞吸积模式
  <https://github.com/wagiham/threejs-cosmic-modes> 与漩涡差分自转
  <https://github.com/MiniMax-AI/skills/blob/main/skills/shader-dev/reference/particle-system.md>。
  → **取用**:在极坐标漩涡路径上**叠加一段指数外冲**:`r = r_漩涡 + A·easeOutCubic(p/pIn)·(1−smooth(p))`
  —— 起飞瞬间先炸开、随即被漩涡接管,两段无缝。
- 前情沿用:hashed-discard 溶解(炸开前滴体的「破」)、`uNightDots` 夜色分支(液滴同款暖橙)。

## 2. 方案

### 2.1 光点外观(新材质,替换 LUX_SPARK_*)

| 项 | 值 | 说明 |
| --- | --- | --- |
| 形状 | 单位半球局部半径 `rl = length(position.xz)` ∈ [0,1] | 复用现有透镜几何,不新增几何 |
| 廓线 | `fall = 0.55·(1−rl)^5 + 0.45·(1−rl)^1.6`;**rgb 与 alpha 取同一条廓线**(`col·a` / `a`) | 细亮核 + 宽淡晕;同廓 → 只亮不暗 —— ⚠ 初版「宽 alpha + 细 core」分廓,边缘把背景压暗成**暗环**,读作「带暗边的小珠」(证据帧抓到,已改) |
| 日间色 | `vec3(1.0, 0.97, 0.90) × 1.5` | 水面上的近白暖光点,越 bloom 阈值出晕 |
| 深夜色 | `vec3(1.0, 0.70, 0.30) × 1.25` | **与 `LUX_DROPLET_FRAG` 夜色分支同色**(委托方:「和原液滴一样」) |
| 压暗 | `× mix(1, 0.42, uDim)` | 与其余材质一致(过渡段压暗) |
| 混合 | **预乘**:`blendSrc=One, blendDst=OneMinusSrcAlpha`;输出 `vec4(col·a, a)` | 防柔边暗环;亮核自然「加」出光 |

### 2.2 尺寸与数量

- 光点半径(体积小):**0.004–0.007**(≈滴径 1/3;现为 0.009–0.013),抵达前缩到 ≈60%。
- 爆散火花(同物种,一起换):0.009 → 0.005(现 0.013 → 0.007);**数量仍 48**。
- 池容量 96 → **160**(点变小 → 密度补偿;汇聚段用满,**爆散段仍只用前 48 槽**)。

### 2.3 炸裂与悬浮飘散(运动)

```
p    = span01(t, t0, t1)
炸裂  burst = A·k_i·easeOutCubic(span01(p, 0, 0.26)) · (1 − smooth01(span01(p, 0.20, 0.62)))
              A = 0.026(米,≈滴径量级),k_i ∈ [0.6,1.4] 逐点抖动
漩涡  r    = r0·(1 − easeInCubic(p)) + burst        // 外冲叠加在漩涡路径上
角    θ    = θ0 + 3.4·p^1.7                        // 上一轮已验证:差分自转 = 漩涡
悬浮  h    = hBase_i + hArc_i·sin(π p)             // hBase 0.008–0.016(**离水悬浮**),
                                                     hArc 0–0.010
飘散  wx/wy = 0.0035·sin(t·W_i + φ_i)·sin(π p)     // 中段最大、两端归零的游移
出现  a    = min( span01(t, t0, t0+0.035), 1 − span01(p, 0.72, 1) )   // 快闪出现 = 「炸」
```

- **滴体的「炸」**:溶解窗 0.20 → **0.14s**(更快),光点喷出窗 0.08 → **0.04s**(更齐),
  旧桥卷没随之前移到 0.36s(仍早于第一次引擎删滴)。
- 时间线其余不动:总长 3.30s、爆散点 1.75、巨滴凝聚 0.63→1.30、凝滞 1.30→1.75。

## 4. 测试点(步骤 5)

1. **炸裂**:起飞瞬间半径**先增后减**(存在 p₁ 使 r(p₁) > r(0),且峰值 ≤ r0+0.04);
   随后单调收缩至中心 ✓(替换原「半径单调收」例)。
2. **体积小**:光点半径 ∈ [0.003, 0.008](全程 ≤ 滴径的 60%)。
3. **悬浮**:h > 0 全程(起点即离水),中段抬升、抵达回落到 hBase。
4. **快闪出现**:t0 之后 0.035s 内 a=1(「炸」的读感);抵达前按 veil 归零。
5. **飘散**:游移有界(≤0.004)+ 确定性(同参复现逐位一致)。
6. **爆散段**:数量仍 48(`i ≥ SPARK_COUNT` 恒 null)、运动曲线**原样**(既有例不动)。
7. **夜色**:着色器守护例断言 `uNightDots` 分支与预乘输出存在(`luxFx.test.ts` 守卫风格)。

## 6. 风险与边界

1. **点变小后的密度**:靠池 96→160 补偿;若仍偏稀,可再加池(代价仅逐实例矩阵)。
2. **白天水面偏亮**(整帧均值 ~155/255):近白核 1.5 需靠 bloom(阈值 0.7)出晕才「发光」;
   若静帧里读不出,首选项是抬核亮度而不是加 add 混合(夜闪纪律:时间调制项与加性项都要钳)。
3. **预乘混合换掉原 NormalBlending**:爆散段外观随之改变(委托方已裁定「一起换」);
   夜闪/白爆纪律不变(核亮度 1.25 远低于液滴夜间 1.15×core 的量级)。
4. 光点仍不带物理(不搅动水面),与既有边界一致。
