## 需求与实现

| # | 需求(委托方原话要义) | 实现 |
|---|---|---|
| 1a | 液滴 z 轴拉长至 1.0 | 液滴几何球冠高/半径比 LENS_H 0.3→**1.0**(R=(1+H²)/2H=1,θ=90° 正半球);viewer 与 luxShaders 的 LENS_H 同步改值,实例缩放/法线修正公式不变。桥尖端随之解析重推:半球面高 r·√(1−ρ̂²) 与轴高(中面 0.5r)的交点 ρ̂=√3/2≈**0.866**(与缩放/ε 无关,解析常量) |
| 1b | 液桥两端轻微放宽,仍与液滴完美衔接,隐藏插入液滴内部分 | 端径 0.12→**0.16r**;尖端改落在 0.866r 的「表面-轴高交点」上(此前 0.78 略深入内部):桥可见段恰好从液滴表面长出,**内部无几何段**(委托方「隐藏插入部分」按构造成立,不依赖深度遮挡——本批液滴转透明后深度遮挡不再可靠,几何裁除是前提);端部 12% 桥长 smoothstep 收细到 0,起伏/悬浮/退场全态不脱节 |
| 1c | 波浪速度减缓 | 环境波涛谱相速度整体减半(0.55–0.75 → 0.28–0.38,AMBIENT_WAVES 表唯一真源) |
| 1d | 液面、液桥改透明淡蓝;液滴改水材质(原玻璃球),颜色透明度与液面一致 | 液面:淡蓝染色 0.35→**0.55**、alpha 0.22–0.85→**0.15–0.7**。液桥:内体基色改淡蓝 `(0.55,0.78,0.95)×lit×1.5`,天光裹挟项减弱,常态 alpha 0.30(委托方指定值不变)。液滴:**重写为水材质**——去掉深色内体(uDropDarken 弃用,参数保留)与 F×2.2 过强反射,改为与液面同族:Snell 折射看水底(半球透镜放大扭曲)+ Fresnel 天空反射 + 淡蓝染色 0.35,`alpha = mix(0.15, 0.7, F)` 与液面同式;材质 transparent+depthWrite:false,renderOrder=5(液桥 10 之后混合) |
| 2 | 水底层光影过于粗糙,尤其液滴投影 | ①液滴软影重写(原:单一径向 smoothstep 圆斑):`dropShadowField` = **太阳方向投影偏移**(影心沿太阳反向平移 ∝ 池深,低仰角自动拉长)+ 本影/半影两层(1.05r→0.4r 本影核 + 2.8r→0.85r 宽半影)。②水底 mesh 着色此前**写死浅蓝渐变、bottomAlbedo 只作用于折射视图**——缺陷修复:mesh 渐变改由 albedo 调制(×2.15 按正午标定,白天观感不变)。③shadeBottom 与水底 mesh 的重复实现收敛为共享助手(dropShadowField/nightDotsGlow) |
| 3 | 深夜水底改深蓝色;金色光点面积过大且稀疏(参考 docs/水底夜晚.jpg) | night.bottomAlbedo [0.08,0.09,0.12]→**[0.05,0.10,0.22] 深蓝**(配合 ② 的 mesh 修复才真正生效);光点点阵周期 0.05→**0.034m**(约 2.2× 密度)、点径 smoothstep(0.16,0.03)→**(0.105,0.022)**;金色保留(第五批委托方指定色,r>g>b 测试锁定),亮度受局部焦散调制 → 光点顺波纹亮带聚簇,贴近参考图的点簇观感。其余时段 bottomAlbedo 同步蓝化(晨雾蓝/池水蓝/暮色蓝),避免水底露棕褐 |

## 实测(浏览器端到端)

- 清晨网络场景(拉近):液滴为透明半球水珠(可见水底透镜扭曲 + 边缘 Fresnel 亮环),
  淡蓝液桥由液滴表面锥形长出、端部轻微放宽、无插入段无缝隙;波涛明显变缓。
- 深夜:水底深蓝,金色光点细密散布、顺波纹聚簇;月光下液滴呈发光半球、
  液桥带月光镜面亮带;液滴投影沿月光反向拉长,柔和成锥。
- 137/137 测试绿(tsc/build 通过);presets 测试锁定的金色 r>g>b、
  bridgeOpacity=0.3、dropletDarken<1 等约束全部满足。

## 遗留观察项(非缺陷)

1. 正午时段整体仍偏曝(既有分级,未在本批范围);新水底亮度按正午对齐旧版。
2. 液滴转透明后,液桥从液滴后方经过时会透过液滴可见(符合透明水语义;
   如需遮挡可在液桥着色加逐滴遮挡估计,成本较高暂不做)。
3. 半球液滴与物理凹陷核(按球缺浸深建模)的形态差异是风格化声明,物理侧未动。
