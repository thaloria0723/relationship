# 启动指南 · 水体物理仿真（灰模）

日期：2026-09-06。配套文档：`docs/物理模型实施文档-2026-09-06.md`（规格与验收表）。

## 1. 环境要求

- **Node.js** ≥ 20（Vite 8 要求）
- npm（随 Node 附带）
- 现代浏览器（Chrome / Edge / Safari / Firefox 均可，需支持 WebGL）

## 2. 首次安装（仅一次）

```bash
cd web
npm install
```

## 3. 启动开发服务器

```bash
cd web
npm run dev
```

启动后终端会显示本地地址（默认 5173，**被占用时自动换端口**，如 5174——以终端实际输出为准）：

```
➜  Local:   http://localhost:5174/
```

## 4. 页面清单

| 地址             | 用途                                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------------------- |
| `/demo.html`     | **演示时间线页（推荐入口）**：按实施文档 §7 验收脚本自动播放全部物理机制，底部字幕标注「现在应该看到什么」 |
| `/grayview.html` | 自由调试页：随机戳点 + 调试按钮（暂停/单步/重置/线框开关/手动落滴）                                        |
| `/` (index.html) | 占位页（模块③光影渲染接管前）                                                                              |

演示页时间线：

| 时刻   | 内容                                                                      |
| ------ | ------------------------------------------------------------------------- |
| 0s     | 静水 + 3 颗漂浮滴（中央两滴近距）→ 看凹陷（Distortion）与浸深（Buoyancy） |
| 3.5s   | 一滴自 0.15m 落于场中心 → 看下落（Gravity）与入水环纹（Ripple）           |
| 6s     | 左缘波源启动 → 看波列横穿（Wave）与液滴随波漂移（Flow）                   |
| ~9.5s  | 近距两滴毛细靠拢 → 桥接 → **聚合**（HUD 聚合计数 +1，大滴形状振荡）       |
| 13s 起 | 周期落雨持续 → 看稳定性（场面不发散）                                     |

## 5. 操作说明

- **观察视角**：鼠标左键拖拽旋转、滚轮缩放（OrbitControls，观察用，不属于交互模块）
- **HUD 数据**：simTime（物理仿真时间）、液滴数、聚合次数、波场能量
- **按钮**：暂停/继续、单步（逐固定步细看）、重置/重播、线框开关
- **红线提示**：若参数违规（如 CFL 超限），页面顶部显示红字错误——这是灰模里唯一的「颜色」
- 灰模纪律：零灯光零颜色，仅灰色几何（面 #9A9A9A / 线框 #6E6E6E / 底 #C8C8C8 / 液滴 #4A4A4A）

## 7. 常见问题

| 现象             | 处理                                                                                           |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| 端口被占用       | Vite 自动换端口，看终端输出的实际地址                                                          |
| 页面空白/黑屏    | 打开浏览器控制台看报错；确认 WebGL 可用（`chrome://gpu`）                                      |
| 红字「CFL 违规」 | 调参后 c·dt/dx 超限：减小 dt 或 waveSpeed（见实施文档 §4.1）                                   |
| 画面卡顿         | 先关线框；仍卡则降 `gridN`(默认 256→192) 或减 `tracerCount`（改 `web/src/watersim/params.ts`） |
| 想调参           | 参数唯一真源:`web/src/watersim/params.ts`（默认值 + RANGES 范围表，越界启动即 throw）          |

## 8. 工程结构速查

```
web/
├── demo.html / grayview.html / index.html   # 三个页面入口
├── src/demo.ts                              # §7 演示时间线脚本
├── src/grayview/viewer.ts                   # 灰模查看器(唯一 import three 的文件)
└── src/watersim/                            # 物理引擎(零渲染依赖)
    ├── engine.ts      # 门面:固定步长管线
    ├── field.ts       # 水面场:浅水波+流+凹陷核
    ├── droplet.ts     # 液滴单体:浮力/落体/形状弹簧
    ├── pairs.ts       # 液滴间:碰撞/毛细/聚合
    └── params.ts      # 参数唯一真源
```
